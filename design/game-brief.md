**One-sentence pitch:** ดวลเวทมนตร์ PvP แบบ battleground ในเบราว์เซอร์ ต่อสู้แบบ Hogwarts Legacy บนแผนที่ที่พังได้แบบ Battlefield เล่นกับเพื่อนได้ไม่รู้จบ

## Core loop
- เข้าแมตช์ FFA (2–6 คน) → ยิงเวท โล่/parry หลบ ใช้สกิลตาม path (ไฟ น้ำแข็ง สายฟ้า ดิน ลม)
- ใช้สภาพแวดล้อม: ทำลายกำแพง/ตึกเพื่อเปิดทางหรือขุดศัตรูออกจากที่กำบัง
- ใครได้ 10 kill ก่อนชนะ → กลับล็อบบี้ → เริ่มแมตช์ใหม่ทันที

## Player goal & fail state
- เป้าหมาย: ได้ 10 kill ก่อนคนอื่นในแมตช์ FFA
- ตาย = เกิดใหม่ (แมตช์ไม่จบ); แมตช์จบเมื่อมีคนครบ 10 kill
- เกมเล่นต่อเนื่อง ไม่มีเนื้อเรื่องหรือจุดจบระยะยาว

## MVP — what must exist to be the game
- โหมด FFA 2–6 คนออนไลน์ (host เป็นผู้คำนวณ, PeerJS)
- ระบบต่อสู้: ยิงเวท, โล่ + parry, หลบ, 4 สกิล + อัลติเมตต่อ path
- 5 path เวท พร้อม VFX ของแต่ละสกิล
- แผนที่ที่ทำลายได้ (ตึกในเมือง: แกนกลางไม่พัง วงนอกพังได้)
- มุมกล้องข้ามไหล่ + เล็งด้วยเป้ากลางจอ
- HUD: HP/โล่, การ์ดสกิล, คะแนน kill
