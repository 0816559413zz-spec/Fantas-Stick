# มาตรฐานสกิลที่ทำให้ตัวปลิว (Ragdoll / Launch)

ใช้เมื่อออกแบบสกิลที่โดนแล้ว "ตัวปลิวจริง" — ตัวลอยขึ้นและกระเด็นในเกมจริง (ไม่ใช่แค่ภาพ) ระหว่างนั้นทำอะไรไม่ได้ ตกพื้นเป็นตัวอ่อน แล้วลุก

## กรอก 3 ค่า (ทุกสกิลที่มี Ragdoll)

```
Ragdoll:   มี / ไม่มี
  นาน:       __ วิ   (time)  — นับจากโดน จนลุกและทำอะไรได้อีกครั้ง (ลอย + นอนพื้น รวมกัน)
  ลอยสูง:    __ ม.   (up)    — จุดสูงสุดที่ตัวลอยขึ้น (1 ม. = 1 หน่วยเกม, ตัวละครสูง ~2 ม.) • 0 = ไม่ลอย ล้มแค่พื้น
  แรงผลัก:   __      (push)  — แรงกระเด็นแนวนอน หน่วยเดียวกับ "ผลัก" ทุกสกิล (ทิศ = ออกจากจุดที่โดน)
```

เทียบแรงผลักกับของที่มีในเกม: 220 = ผลักเบา (ดันจากพื้นที่) • 350 = ผลักกลาง • 650–900 = แรงสุดที่มีตอนนี้ (สายดิน) • ทดสอบแล้ว: ลอย 3 ม. + แรง 700 = ลอยราว 1 วิ กระเด็นไกล ~30 ม. บนพื้นเรียบ

**ตัวเลขทั้งหมดเป็นของคนออกแบบสกิล** — Claude ไม่ตั้งเอง

## กติกาที่ระบบทำให้เอง (เหมือนกันทุกสกิล)

- ระหว่าง "นาน": เดิน/ร่าย/พุ่ง/โล่ ไม่ได้ ตกจากไม้กวาด
- กลางอากาศ: ตัวไหลต่อ (แรงต้านอากาศน้อย) • แตะพื้น: ไถลแล้วหยุดเหมือนผลักปกติ
- โดนซ้ำระหว่างปลิว: นับเวลาใหม่ตามค่าที่ยาวกว่า, ลอยขึ้นใหม่ได้
- ตัวกำลังอมตะ / ล้มรอชุบ / ตาย = ไม่ปลิว
- ศัตรู (มอนสเตอร์) / สัตว์อัญเชิญ: โดนแค่แรงผลัก (ยังไม่มีตัวอ่อน) • บอส/ตัวใหญ่ ผลักได้ 25% ตามกฎเดิม
- ภาพ: ตัวอ่อนเต็มตัว (ทุกคนเห็นตัวปลิวตรงกัน ส่วนท่าแขนขาคำนวณบนแต่ละเครื่อง) → หมดเวลา ค่อยๆ ลุก 0.4 วิ

## ชนกำแพง (เตรียมไว้แล้ว ยังไม่มีผล)

- ตัวที่ปลิวชนของแข็งเร็วกว่า 250 (หน่วยเดียวกับแรงผลัก) = เกิดเหตุการณ์ "ชนกำแพง" (`rgwall`) ตัวหยุดเกือบสนิท
- ยังไม่มีผลต่อการเล่น (ไม่พัง ไม่โดนดาเมจเพิ่ม) — ที่วางไว้: `launchWallHit` ใน `js/12-launch.js`
- อนาคต (ผู้ใช้วางแผน): กำแพงแตก / ดาเมจชน — ต้องตัดสินก่อน: ความเร็วเท่าไหร่ถึงพัง, พังอะไรได้บ้าง, ดาเมจชนกี่หน่วย, คนปลิวโดนดาเมจด้วยไหม

## ยังไม่ได้ตัดสิน (ถามผู้ใช้ก่อนใช้)

- โล่ / Stand / ร่างพิเศษ กันการปลิวได้ไหม (ตอนนี้: ไม่กัน ยกเว้นอมตะ)
- ปลิวไปชนเพื่อนร่วมทีม/ศัตรูคนอื่น มีผลไหม
- ลดเวลาเมื่อโดนซ้ำๆ (แบบ CC อื่น) ไหม

## สำหรับคนเขียนโค้ด

```js
// in the skill's hit code (host); S.v.rag = {time, up, push} from the skill numbers
launch(target, fromX, fromY, S.v.rag, caster.id);
```
- host: `js/12-launch.js` (`launch`, `launchTick`, `launchWall`, ค่า `LAUNCH`) • snapshot `lr:1` • ภาพ: `js/48-ragdoll.js` โหมด `launch`
- ทดสอบ: `WD.launch(WD.G.players[WD.NET.myId], x, y, {time:2.2, up:3, push:700})`
