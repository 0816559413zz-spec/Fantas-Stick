# กฎ UI ของแอป Tool (ใช้กับ Tool ทุกตัว)

Tool = หน้าที่ใช้ทำงานกับเกม ไม่ใช่ตัวเกม: VFX Studio, ปรับค่าเกม, Storyboard, โน้ตปัญหา, คู่มือ, หน้าดูแบบร่าง ฯลฯ
ทางเข้าเดียวคือ **ศูนย์รวม Tool** → `hub.html` (เปิดด้วย `Tools.bat`) รายการอยู่ใน `hub/tools.json`

## 1. ดูและความรู้สึก
- **โทนดำ/เทาเข้มแบบ Studio มืออาชีพ** (เหมือน Blender / Unity / Figma มืด) พื้นเรียบ ไม่มีลวดลาย
- **ห้ามใช้ธีมเกม:** ทอง/ม่วง, ฟอนต์ Kanit/แฟนตาซี, พื้นหลังดาว/ปราสาท, กรอบหรูหรา, เอฟเฟกต์เรืองแสง (ภาพของเกมที่เป็น "เนื้อหา" เช่น พรีวิว 3D แสดงได้ตามปกติ แต่เปลือก UI ต้องเป็นแบบ Tool)
- สีเน้นมีสีเดียว = ฟ้า `--acc`; เขียว/ส้ม/แดงใช้บอกสถานะเท่านั้น (`--sok/--swarn/--serr`)
- ฟอนต์ `var(--ui)` (Segoe UI/Noto Sans Thai) ตัวเลข/โค้ด `var(--fu)` ขนาดพื้นฐาน 13px กระชับ ไม่ใหญ่โต

## 2. ทำยังไง
1. ใส่ `<link rel="stylesheet" href="hub/tool-ui.css">` — ใช้ตัวแปรสีจากไฟล์นี้ (`--bg0..4`, `--ln/--ln2`, `--tx/--tx2/--tx3`, `--acc`) **ห้ามฮาร์ดโค้ดสีใหม่** ถ้าขาดสีให้เพิ่มในไฟล์กลาง
2. มีปุ่ม **"◂ Tool"** (`<a class="tl-home" href="hub.html">`) ที่แถบบนซ้ายสุดทุกหน้า
3. ลงทะเบียนใน `hub/tools.json` (`node tools/check.js` จะฟ้องถ้าหน้า `.html` ที่รากยังไม่ลงทะเบียน)
4. Tool ที่เป็นหน้าเดียวเปิดผ่านเซิร์ฟเวอร์ `tools/serve.py` ไม่ต้องทำ `.bat` แยก ใช้ `Tools.bat`

## 3. เสียง: ปิดเป็นค่าเริ่มต้น
- ทุก Tool **ไม่มีเสียงตอนเปิด** ผู้ใช้กดเปิดเองได้ที่ปุ่ม 🔇/🔊 (มุมขวาบนของฮับ และในแถบของ Tool ที่มีเสียง)
- สวิตช์เดียวใช้ร่วมกันทุก Tool: `localStorage['fs_tool_sound']` (`'1'` = เปิด) จัดการด้วย `hub/tool-sound.js` (`ToolSound.button()` / `<span data-tool-sound>`)
- เกมที่ฝังใน Tool (`index.html?studio`, `?tunetool`) อ่านคีย์เดียวกันใน `js/18-audio.js` (`TOOL_CTX`, `masterGain()`) — ปิด = `MASTER.gain` เป็น 0, เปิด/ปิดแล้วมีผลทันทีโดยไม่ต้องรีเฟรช
- Tool ใหม่ที่ **เล่นเสียงเอง** ต้อง: ไม่เล่นอะไรจนกว่า `ToolSound.get()` เป็น true, ใส่ปุ่ม `ToolSound.button()` ในแถบบน, และฟัง event `storage` ของคีย์นี้
- ตัวเกมปกติ (`index.html` ไม่มี `?studio`/`?tunetool`) ไม่ผูกกับสวิตช์นี้

## 4. ของที่ใช้ซ้ำได้ (`hub/tool-ui.css`)
`.tl-bar` แถบบน • `.tl-btn` (`.pri`/`.on`) ปุ่ม • `.tl-sel` `.tl-in` ช่องกรอก • `a.tl-home` ปุ่มกลับฮับ • `.tl-snd` ปุ่มเสียง
Tool เดิม (Studio/Storyboard/Tune/Bugs) ใช้ชุดสีเดียวกันนี้แล้ว (Studio/Storyboard มีตัวแปรชื่อเดิมของตัวเองผูกกับค่าเดียวกัน)
