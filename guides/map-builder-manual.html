สารบัญ Map Builder คืออะไรเปิดใช้งานหน้าจอคุมกล้อง เครื่องมือ 10 ตัวย้าย หมุน ย่อขยายทำแผนที่ใหม่ทีละขั้น แผนที่บุกปราสาทชิ้นส่วนปราสาทห้องสำเร็จแผ่นพัง ฉากหลัง (Backdrop)จัดกลุ่มตรวจก่อนส่งไฟล์อยู่ไหน ปุ่มลัดทั้งหมดปัญหาที่พบบ่อย

คู่มือ Map Builder

เครื่องมือสร้างแผนที่ที่เกมโหลดได้จริง ปั้นพื้น ทาสี วางกำแพง ปราสาท ของ และจุดเกิด แล้วกดส่งเข้าเกมได้เลย หน้าตาเครื่องมือเลียนแบบ Unity และข้อความในเครื่องมือเป็นภาษาอังกฤษ คู่มือนี้จึงเขียนชื่อปุ่มเป็นภาษาอังกฤษตามที่เห็นบนจอ

Map Builder คืออะไร

  • Map Builder (mapbuild.html) ใช้ทำ แผนที่จริงที่เล่นได้ ส่งเข้าเกมแล้วเลือกเล่นในล็อบบี้ได้ทันที
  • Map Editor (mapedit.html, ปุ่ม Sketch ▸) เป็นผังร่างมุมบน ใช้คุยออกแบบ ไม่ได้ส่งเข้าเกม
  • ตกลงกันแล้วว่า แผนที่ใหม่ทุกอันทำใน Map Builder ไม่เขียนแผนที่เป็นโค้ด
  • หน่วย: 1 ช่อง = 1 เมตร ตารางพื้นละเอียด 0.5 เมตร ตรงกับตารางชนของเกม เห็นอย่างไรก็ชนอย่างนั้น

เปิดใช้งาน

  1. ดับเบิลคลิก Tools.bat ในโฟลเดอร์เกม (เปิดเซิร์ฟเวอร์ในเครื่องให้เอง)
  2. ในหน้าศูนย์รวม Tool กด Map Builder
  3. เลือกแผนที่จากช่องด้านบนซ้าย หรือกด ＋ New สร้างใหม่
ต้องเปิดผ่าน Tools.bat เท่านั้นถ้าเปิดไฟล์ mapbuild.html ตรง ๆ จะบันทึกและส่งเข้าเกมไม่ได้ เพราะต้องใช้เซิร์ฟเวอร์ในเครื่องเขียนไฟล์ให้

ทำแผนที่ใหม่ทีละขั้น

  1. สร้าง: กด ＋ New ตั้ง id (ภาษาอังกฤษ ไม่เว้นวรรค เช่น moonlake) ชื่อที่จะโชว์ในเกม และขนาดกว้าง×ยาวเป็นเมตร
  2. ตั้งค่าแผนที่: ไม่ต้องเลือกอะไร แล้วดู Inspector: ชื่อ คำอธิบาย ฟ้า หมอก เพลง และติ๊ก โหมดที่เล่นได้ เช่น FFA, Team, บุกปราสาท
  3. ปั้นพื้น ⛰: ยกเนิน ขุดหุบ ทำทางลาด ดูให้ทางที่ต้องเดินขึ้นไม่เป็นสีแดง
  4. ทาผิว 🖌: หญ้า ดิน หิน ทาง น้ำ ฯลฯ (โคลน/น้ำ/น้ำแข็ง/ลาวา ถูกส่งเป็นข้อมูลพื้นที่พิเศษให้เกมด้วย)
  5. สิ่งก่อสร้าง: กำแพง ▤, ชิ้นปราสาท ♜, พื้นชั้นบน ▭, ผนังพังได้ ▦ หรือวางห้องสำเร็จจาก Place
  6. ของและที่กำบัง ◈ ⁘: ลัง ถัง ต้นไม้ หิน บ้าน ของตกแต่ง และแสง (ไม่เกิน 12 ดวง)
  7. จุดเกิด ◈: หมวด System: Spawn Point (แนะนำ 6 จุดขึ้นไป) หรือ Red/Blue Team Spawn สำหรับโหมดทีม
  8. ตรวจ: ดูรายการ ตรวจก่อนส่งเข้าเกม ใน Inspector แก้ข้อที่เป็น ✕ ให้หมด (ข้อ ! เป็นคำเตือน)
  9. ทดลองเล่น ▶: ส่งเข้าเกมแล้วเปิดเกมบนแผนที่นี้ทันที เดินดูว่าติดหรือลอยตรงไหน
  10. ส่งเข้าเกม ⬆ Export: เขียนไฟล์ที่เกมโหลด หลังจากนี้แผนที่จะขึ้นให้เลือกในล็อบบี้
ส่งใหม่ทุกครั้งที่แก้แก้แผนที่แล้วต้องกด ⬆ Export หรือ ▶ อีกครั้ง เกมถึงจะเห็นของใหม่ ระบบบันทึกอัตโนมัติแค่บันทึกต้นฉบับ ยังไม่ได้ส่งเข้าเกม

แผนที่บุกปราสาท

ใช้เครื่องมือ Place ◈ หมวด Siege mode และติ๊กโหมดบุกปราสาทในค่าแผนที่

ของใส่ยังไง
Core (แกน)วางตามลำดับ ใส่เลข n = 1, 2, 3 … ใน Inspector (แกนเลขน้อยถูกบุกก่อน) ตั้งขนาดได้
Attacker / Defender Spawnจุดเกิดฝ่ายบุก (sgA) และฝ่ายรับ (sgB) เฟสละ 1 จุดต่อฝ่าย ใส่เลขเฟส ph
Phase Areaกรอบสี่เหลี่ยมพื้นที่เล่นของแต่ละเฟส (ใส่ ph) ใช้หลายกรอบต่อเฟสได้ แกนและจุดเกิดของเฟสนั้นต้องอยู่ในกรอบ
กำแพง/ประตูเป้าหมายเลือกกำแพง → Inspector ตั้ง "เป้าหมายบุกปราสาท" เป็น wall (พังได้) หรือ gate (ประตูที่เปิดเมื่อแกน 1 แตก)

ตัวตรวจเช็กให้ว่าแกนเรียงเลขครบ ทุกเฟสมีจุดเกิดสองฝ่าย มีพื้นที่เล่น และของอยู่ในกรอบ ถ้าติ๊กแค่บุกปราสาท กด ▶ จะเปิดเกมโหมดบุกปราสาทให้เลย คุณเป็นฝ่ายบุก มีบอทฝ่ายรับ 1 ตัว

ตัวอย่างให้เปิดดูsiege-demo (3 เฟส ประตู กำแพงเป้าหมาย รั้ว เพดาน) และ fcs-file (ปราสาทหลักทั้งแผนที่) เลือกจากช่องแผนที่ด้านบนได้เลย

ชิ้นส่วนปราสาท ♜

  • ชิ้นที่มี: wall กำแพงตรง • corner มุม L • tower หอคอย (กลม/เหลี่ยม) • gate ประตูเมือง (มีบานไม้พังได้) • keep ตึกใหญ่ • stairs บันได • ramp ทางลาด • walk ทางเดินยก • bridge สะพาน • free ทรงอิสระ
  • วาง: เลือกชิ้น แล้วคลิก • ,. หมุน 45° (Shift = 15°) • ปลายชิ้นดูดติดกันเองภายใน 1.6 ม. • คลิกบนยอดกำแพงหรือทางเดิน = วางต่อที่ความสูงนั้น
  • ตัวเลือก: ฟันปลา ทางเดินบนยอด หลังคา หอมุม ราว เสารอง ประตู แก้ใน Tool Settings / Inspector
  • พังได้ ปิดเป็นค่าเริ่ม ถ้าเปิด กำแพงจะแตกเป็นช่วงละประมาณ 4 ม. แต่จะไม่มีฟันปลาและทางเดินบนยอด
  • ทรงอิสระ: คลิกวาดรูปปิดทีละจุด → ได้ทรงตันดึงขึ้นสูง ปรับ "หุบยอด" ได้ (1 = ตรง, 0 = แหลม) ลากจุดสีฟ้าเพื่อปั้นรูป
  • ช่องประตูเดินลอดได้เมื่อสูง ≥ 2.2 ม.

ห้องสำเร็จ (prefab)

  • ห้อง = แผนที่ที่ id ขึ้นต้นด้วย room- ทำเหมือนแผนที่ปกติบนพื้นราบ
  • วางห้อง: Place → หมวด Prefab Rooms → คลิก = จุดกลางห้อง หมุนทีละ 90°
  • แก้ไฟล์ห้องครั้งเดียว ทุกแผนที่ที่ใช้ห้องนั้นเปลี่ยนตาม
  • แตกห้องเข้าแผนที่: เลือกห้อง → Inspector กดปุ่มแตกห้อง → ของในห้องกลายเป็นของปกติ แก้ได้ทุกชิ้น และไม่ผูกกับไฟล์ห้องแล้ว
  • ตัวเลือก Unbreakable = ผนังทั้งห้องพังไม่ได้ • Roof collision = ยืนบนหลังคาได้
  • มีให้ใช้: ห้องโถงใหญ่ room-greathall • ลาน 5 แบบ (ตลาด ลานฝึก สวนน้ำพุ โรงตีเหล็ก ค่ายทหาร) • บ้านหิน 5 แบบ (กระท่อม คฤหาสน์ จั่ว 3 ลูก หอ เพิงพิงกำแพง)

แผ่นพัง ▦

  • เลือกวัสดุ แล้วคลิกลากแนวผนัง ทั้งเส้นอยู่กลุ่มเดียวกันและค้ำกัน คลิกจุดแรก = ปิดวงเป็นบ้าน
  • แบบพัง: เป็นรู + กองซาก • ผิวหลุดเป็นชั้น • แตกทั้งแผ่น • เป็นรูไม่มีซาก
  • ปุ่ม เจาะประตู (1.4×2.4 ม.) และ เจาะหน้าต่าง (1.2×1.2 ม.) • ทำหลังคาเอียงหรือจั่วสามเหลี่ยมได้
  • ลองทุบ: ใช้ Select แล้วคลิกบนแผ่น = ทุบ 1 ช่อง (Shift = 3×3) สีแดง = โดนทุบ สีส้ม = ส่วนที่จะร่วงตาม ไม่บันทึกลงไฟล์
  • บ้าน house ที่วางไว้ เลือกแล้วกด "แตกเป็นแผ่นพัง" เพื่อแก้ทีละแผ่นได้
  • ระวังจำนวนช่องรวม: เกิน 6,000 ตัวตรวจจะเตือน เกิน 12,000 ส่งเข้าเกมไม่ได้

ฉากหลัง (Backdrop) 🌊

  • เป็นพื้นที่รอบนอกแผนที่ไกลออกไป 600 ม. ทุกด้าน เกมวาดให้สวย แต่เดินไปไม่ได้และไม่มีที่ชน
  • เริ่มจากแบบสำเร็จ: coast หน้าผาริมทะเล • island เกาะ • valley หุบเขา • plains ทุ่ง • lake ทะเลสาบ • flat ราบ
  • แปรง: Raise / Lower / Smooth / Flatten / Set Height / Noise / Paint / Trees • Sea Stack คลิก = เพิ่มหินกลางทะเล, Shift+คลิก = ลบ
  • ตั้งระดับน้ำทะเล และติ๊ก on เพื่อให้เกมใช้

  • ! คำเตือน ส่งได้แต่ควรดู เช่น จุดเกิดอยู่บนทางชัน ชิดกำแพง เดินไปหากันไม่ถึง แสงเกิน 12 ดวง ใต้ชั้นบนเตี้ยกว่า 2.8 ม. หรือพื้นสูงต่ำเกินช่วง −5 ถึง +20 ม.

เดินขึ้นเนินไม่ได้

เปิด Too Steep ดู ส่วนที่เป็นสีแดงชันเกินไป ใช้ Sculpt → Smooth หรือ Ramp ทำทางลาด

เดินทะลุของ หรือชนของที่มองไม่เห็น

เปิด Colliders ดูที่ชนจริง แล้วเช็กช่อง Collides และขนาดที่ชนใน Inspector (ต้นไม้ชนแค่ลำต้นเป็นค่าเริ่ม)
