# MUSIC — ทำเพลงประกอบเกมเอง (ออเคสตราเสมือน, ฟรี)

คู่มือสำหรับทีมที่จะแต่งเพลงประกอบ Fantas-Stick เองและดูแลเองระยะยาว โดยไม่ใช้เครื่องดนตรีจริงและไม่เสียเงิน
เพลงชุดปัจจุบันเป็นเพลงยืม (Kevin MacLeod CC BY / CC0, ดู `audio/CREDITS.md`) — เป้าหมายคือแทนที่ทีละเพลงด้วยเพลงของเราเอง

---

## 1. เกมเล่นเพลงอย่างไร (สิ่งที่ต้องรู้ก่อนแต่ง)

- โค้ด: `js/18-audio.js` (`wantTrack`, `mapTrack`, `musicEl`, `fileMusicTick`)
- ไฟล์: `audio/music/<ชื่อ>.ogg` — **วางไฟล์ชื่อเดิมทับ = เปลี่ยนเพลงได้ทันที ไม่ต้องแก้โค้ด**
- เล่นแบบสตรีม (`<audio>`), fade เข้า 2 วินาที / ออก 1.5 วินาที, ระดับเสียงเพลง `MUSF_VOL = 0.5`
- Lobby โหลดเพลงของแมปที่เลือกไว้ล่วงหน้า (`audioPrefetch`)

| ไฟล์ | เล่นเมื่อ | ชนิด |
|---|---|---|
| `menu.ogg` | หน้าเมนู / นอกเกม | loop |
| `castle.ogg` | แมปทั่วไป (ค่าเริ่มต้น) | loop |
| `forest.ogg` | แมป `forest`, `hogsmeade`, `lake` | loop |
| `pitch.ogg` | แมป `pitch`, `meadow`, `ruins` + โหมด `race`, `quid` | loop |
| `imp.ogg` | โหมด `imp` | loop |
| `boss.ogg` | มีศัตรูบอสอยู่ในฉาก (เริ่มจากต้นเพลงทุกครั้ง) | loop |
| `victory.ogg` | จบเกม ฝ่ายเราชนะ | stinger (เล่นครั้งเดียว) |
| `defeat.ogg` | จบเกม ฝ่ายเราแพ้ | stinger (เล่นครั้งเดียว) |

อยากได้เพลงใหม่ที่ยังไม่มีช่อง (เช่นเพลงเฉพาะแมป, เพลงช่วง Castle Strike, เพลงซ้อนชั้นตามความดุเดือด) → ต้องแก้ `wantTrack` / `mapTrack` ใน `js/18-audio.js` ให้ Claude ทำ

## 2. โปรแกรม (ฟรีทั้งหมด)

### เส้นทางที่แนะนำ: เริ่ม MuseScore → ค่อยขยับไป DAW

| ขั้น | โปรแกรม | ใช้ทำ |
|---|---|---|
| 1 (เริ่ม) | **MuseScore 4 + Muse Sounds** (ติดตั้งผ่าน Muse Hub) | เขียนโน้ต, เสียงออเคสตราคุณภาพสูง, export `.ogg` ตรง |
| 2 (คุมละเอียด) | **Waveform Free** (Tracktion) — หรือ Cakewalk (เช็กสถานะเวอร์ชันฟรีก่อนโหลด) | DAW เต็มตัว, ใส่ VST, mix, effect |
| เสียงเสริมใน DAW | **BBC Symphony Orchestra Discover**, **Spitfire LABS** (ผ่าน Spitfire Audio App) | ออเคสตราครบวง, choir, pad, piano |
| Reverb | **Valhalla Supermassive** (ฟรี) | ห้องคอนเสิร์ต / บรรยากาศกว้าง |
| ซินธ์ (ถ้าต้องการ) | **Vital** (ฟรี) | pad, เสียงเวทมนตร์, ลูกผสม |

หมายเหตุ
- ย้ายงานจาก MuseScore ไป DAW ได้: File → Export → MIDI แล้วเปิดใน DAW
- Reaper ทดลองใช้ได้ครบ 60 วัน แต่หลังจากนั้นเงื่อนไขให้ซื้อ license (~$60) — ไม่นับเป็นทางฟรี
- อุปกรณ์ที่ช่วยมาก (ไม่บังคับ): MIDI keyboard 49 คีย์, หูฟัง closed-back

## 3. ทิศทางเพลงของเกม

- **Leitmotif เดียวทั้งเกม**: แต่งธีมหลักใน `menu` ก่อน แล้วเอาทำนองนั้นไปเรียบเรียงใหม่ในทุกเพลง (ช้า/เร็ว, major/minor, เปลี่ยนเครื่อง) — เพลงทั้งเกมจะเป็นชุดเดียวกัน และแต่งเพลงถัดไปเร็วขึ้น
- ให้เข้ากับงานภาพ watercolor และโลกเวทมนตร์/ปราสาท: ออเคสตราเป็นฐาน, เสริม celesta / harp / choir ให้กลิ่นเวทมนตร์

| เพลง | อารมณ์ | เครื่องหลัก (ข้อเสนอ) |
|---|---|---|
| `menu` | ยิ่งใหญ่แต่อบอุ่น จำง่าย | ทำนองธีมหลักชัด: strings + horn, celesta ประดับ |
| `castle` | ต่อสู้ เร้าใจ | strings staccato/ostinato + percussion + brass |
| `forest` | ลึกลับ มีชีวิต | harp, flute, strings เบา, choir "ooh" |
| `pitch` | สนุก ผจญภัย เร็ว | brass สดใส, snare, woodwinds รัว |
| `imp` | กดดัน น่ากลัว | low strings dissonant, drone, percussion ห่างๆ |
| `boss` | หนัก คุกคาม | full orchestra + choir + low brass + taiko |
| `victory` | แฟนแฟร์สั้น | brass + timpani, จบบน major |
| `defeat` | ตกลง เศร้าสั้น | strings / piano, จบบน minor |

ลำดับที่แนะนำ: `menu` → `castle` → `boss` → `victory` / `defeat` → `forest` / `pitch` / `imp`

## 4. เทคนิคทำให้เหมือนวงจริง

1. **Dynamics**: อย่ากดโน้ตแรงเท่ากันหมด — ใส่ crescendo / diminuendo ตามวลี (ใน DAW ใช้ CC1 Modulation / CC11 Expression)
2. **Articulation**: legato สำหรับทำนอง, staccato / spiccato สำหรับจังหวะ, pizzicato สำหรับช่วงเบา
3. **Humanize**: velocity และจังหวะไม่เป๊ะเกินไป
4. **แบ่งหน้าที่**: ทำนอง / ประสาน / เบส / จังหวะ — อย่าให้ทุกเครื่องเล่นทำนองพร้อมกัน
5. **ช่วงเสียงจริงของเครื่อง**: อย่าเขียนโน้ตเกินช่วงที่เครื่องนั้นเล่นได้ (MuseScore เตือนเป็นสีแดง)
6. **Reverb ห้องเดียวกัน**: ทุกเครื่องผ่าน reverb ตัวเดียวกัน เสียงจะอยู่ในห้องเดียวกัน

แหล่งเรียน (YouTube): Guy Michelmore, Alex Moukala — สอนออเคสตราเสมือนโดยตรง

## 5. สเปกไฟล์ส่งเข้าเกม

| หัวข้อ | ค่า |
|---|---|
| Format | OGG Vorbis (`.ogg`) |
| Sample rate | 44.1 kHz, stereo |
| คุณภาพ | Vorbis quality ~0.5–0.6 (เพลง 2–4 นาที ≈ 2–3 MB เท่าชุดปัจจุบัน) |
| ความดัง | ให้ใกล้เพลงเดิม (ประมาณ -16 LUFS integrated), peak ไม่เกิน -1 dBFS |
| ความยาว loop | 1.5–4 นาที |
| ความยาว stinger | 5–15 วินาที, fade ท้าย |
| ชื่อไฟล์ | ตรงตามตาราง §1 เท่านั้น (ตัวพิมพ์เล็ก) |

### ทำ loop ให้เนียน
- จบเพลงตรงห้องพอดี (เช่น 32 / 64 ห้อง) และให้โน้ตสุดท้ายต่อกลับเข้าต้นเพลงได้ (คอร์ดท้ายพาไปคอร์ดแรก)
- อย่าให้ไฟล์มีความเงียบต้น/ท้าย — ตัดให้ชิดจังหวะ
- หางเสียง reverb ตอนท้าย: วิธีง่าย = ให้ช่วงท้ายเพลงเบาลงก่อนจบ ไม่ให้ถูกตัดกระทันหัน
- ทดลองฟังรอยต่อก่อน export: เล่นซ้ำช่วง 10 วินาทีท้าย + 10 วินาทีแรก
- ข้อจำกัดตอนนี้: เกมใช้ `<audio loop>` อาจมีช่องว่างเล็กมากที่รอยต่อในบาง browser — ถ้าได้ยินชัด แจ้ง Claude ให้เปลี่ยนเป็นระบบ loop แบบไม่มีช่องว่าง

### Export
- MuseScore 4: File → Export → Audio → OGG
- DAW: Render / Export → OGG Vorbis (หรือ WAV แล้วแปลงด้วย Audacity ฟรี)

## 6. ขั้นตอนใส่เพลงใหม่

1. วางไฟล์ใน `audio/music/` ชื่อตามตาราง §1 (ทับไฟล์เดิม)
2. เก็บไฟล์ต้นฉบับ (`.mscz` / project DAW / MIDI) ไว้ใน `audio/src/music/` เพื่อแก้ต่อทีหลัง
3. แก้ `audio/CREDITS.md`: ลบเครดิตเพลงเดิมที่ถูกแทน, ใส่ว่าเป็นเพลงของทีม (ผู้แต่ง, วันที่)
4. เปิดเกมฟัง: เข้าเมนู / แมป / โหมด ที่ใช้เพลงนั้น, เช็ก loop และความดังเทียบกับเพลงอื่น
5. ให้ Claude commit + push (push เข้า `main` = deploy GitHub Pages)

## 7. Claude ช่วยอะไรได้

- เขียน brief ละเอียดต่อเพลง (BPM, คีย์, โครงสร้าง, เครื่อง, ความยาว loop)
- สร้างไฟล์ MIDI / MusicXML โครงธีมหลักให้เปิดใน MuseScore แล้วแก้ต่อ
- เพิ่มช่องเพลงใหม่ในเกม / เพลงซ้อนชั้นตามสถานการณ์ / loop ไม่มีช่องว่าง (แก้ `js/18-audio.js`)
- เช็กความดังและความยาวไฟล์ที่ export มา
