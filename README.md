# ✦ Fantas Stick ✦

**▶ เล่นเลย: https://0816559413zz-spec.github.io/Fantas-Stick/**

เกมดวลเวทมนตร์ 3D มุมกล้องหลังไหล่ เลือกสายเวทแล้วสู้กับเพื่อนหรือบอท — เล่นในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

> โปรเจกต์แฟนเมดทำเล่นเองกับเพื่อน ไม่ได้ใช้เชิงพาณิชย์ • เกมยังอยู่ระหว่างพัฒนา สายเวท ตัวเลข และโหมดเปลี่ยนได้

## 🎮 โหมดเกม (ในเมนูหลักตอนนี้)
- **Free For All** (2–12 คน) — ทุกคนคือศัตรู ใครได้ 10 kill ก่อนชนะ
- **Team PvP** (2–12 คน สูงสุด 6v6) — ทีมไหนได้ 15 kill ก่อนชนะ
- **Training ห้องฝึก** (1–6 คน) — หุ่นซ้อม ลองคาถา เสกมอนสเตอร์ ปิดคูลดาวน์ได้ (กด **P** เปิดเมนูทดลอง)
- **Castle Siege บุกปราสาท** (2–12 คน) — ทีมฟ้าบุก ทีมแดงรับ ร่ายทำลายแกน 3 จุดตามลำดับก่อนหมดเวลา • เป็นรุ่นพื้นฐาน ผังปราสาทจริงยังออกแบบอยู่ (`designs/castle-gameplay-concept.md`)

ในห้องเติมบอทได้ เลือกสายและระดับความเก่งของบอทได้

**พักไว้ / ยังไม่อยู่ในเมนูหลัก:** Dungeon Co-op (พักชั่วคราว) • ดวล 1v1, ควิดดิช, แข่งไม้กวาด, แบทเทิลรอยัล, หาลอร์ดโวลเดอมอร์ (โค้ดยังอยู่ ยังไม่ได้ใส่ในเมนูใหม่)

## 🪄 สายเวท (7 สาย)
แต่ละสายมีโจมตีปกติ โล่ คาถา 4 ช่อง (Q/E/R/F) และเวทโบราณ (X) ของตัวเอง จัดคาถาได้ที่ **จัดคาถา GRIMOIRE** ในเมนู

| สาย | แนวการเล่น |
|---|---|
| 🔥 ไฟ | สะสม Burning สูงสุด 5 ชั้น แล้วดีดนิ้วระเบิด |
| ❄️ น้ำแข็ง | นักดาบน้ำแข็ง สลับประชิด/ไกลด้วย V |
| ⚡ สายฟ้า | ว่องไว ลำสายฟ้าระยะประชิด Dash ทะลุศัตรู |
| ⛰️ ดิน | สถาปนิกสนามรบ มี Stand หินต่อยแทนเรา |
| 🌪️ ลม | พริ้วไหวกลางอากาศ บินได้ |
| 💧 น้ำ | เล่นง่าย ยิงน้ำไกล คลื่นผลัก ฮีลตัวเอง |
| 🌿 ธรรมชาติ | แส้หนามและปลูกพืช ช่วยทีมคุมพื้นที่ |

## 🗺️ แผนที่
ลานปราสาท • ป่ามืด • โถงใหญ่ • ฮอกส์มี้ด • ทะเลสาบ • ทุ่งหญ้า • สนามควิดดิช • ซากปรักหักพัง • หุบเขา (ไฟล์อยู่ใน `assets/maps/`) — ห้องฝึกใช้ Test Place และบุกปราสาทใช้แผนที่ของโหมดเอง

## 👫 เล่นกับเพื่อน
1. เปิดเกมที่ **https://0816559413zz-spec.github.io/Fantas-Stick/** ด้วย Chrome / Edge
2. คนสร้างห้อง: กด **PLAY เล่น** → เลือกโหมด → ได้ห้องพร้อมรหัส 5 ตัว (กดปุ่มลิงก์เพื่อคัดลอกลิงก์เชิญได้)
3. เพื่อน: กด **JOIN เข้าห้องเพื่อน** → ใส่รหัส 5 ตัว
4. คนสร้างห้องกด **เริ่มเกม**
5. พูดคุย: กดปุ่มไมค์ในห้อง แล้ว **กด T ค้าง** เพื่อพูด (เปลี่ยนเป็นเปิดไมค์ตลอดได้)

ต้องต่ออินเทอร์เน็ตตอนสร้าง/เข้าห้อง (ใช้ WebRTC ผ่าน PeerJS) — ข้อมูลเกมและเสียงวิ่งตรงระหว่างเครื่อง • ต่อเน็ตไม่ได้ = เล่นคนเดียวกับบอทแบบออฟไลน์

## ⬇️ ติดตั้ง / อัปเดตเกมในเครื่อง (`Update Game.bat`)
ใช้เมื่ออยากได้เกมทั้งโฟลเดอร์ในเครื่อง (เช่น ใช้ VFX Studio / สตอรี่บอร์ด / เล่นแบบไม่ผ่านเว็บ) — ถ้าแค่เล่น เปิดลิงก์ข้างบนได้เลย ล่าสุดเสมอ
- **เครื่องใหม่:** ดาวน์โหลดไฟล์ [`Update Game.bat`](https://github.com/0816559413zz-spec/Fantas-Stick/raw/main/Update%20Game.bat) ไปไว้ที่ไหนก็ได้ → ดับเบิลคลิก → เกมทั้งหมดจะลงในโฟลเดอร์ `Fantas-Stick` ข้าง ๆ ไฟล์
- **อัปเดต:** ดับเบิลคลิก `Update Game.bat` ในโฟลเดอร์เกม → ดึงเวอร์ชันล่าสุด บอกว่ามีอะไรเปลี่ยน แล้วเปิดเกมให้ (งานที่แก้ค้างในเครื่องไม่หาย)
- มี [Git](https://git-scm.com/download/win) จะเร็วกว่า (ไม่มีก็ได้ — จะดาวน์โหลด ZIP แทน) • มี [Python](https://www.python.org/downloads/) จะเปิดเกมในเครื่องให้ (ไม่มี = เปิดเกมออนไลน์)

## 🧰 เครื่องมือทำเกม (`Tools.bat`)
ดับเบิลคลิก `Tools.bat` เพื่อเปิดศูนย์รวม Tool: VFX Studio (ทำเอฟเฟกต์) • Map Editor (วาดผังแผนที่) • สตอรี่บอร์ด VFX • โน้ตบั๊ก • เครื่องมือปรับค่าเกม — ในเกมกด **F8** เพื่อปรับค่าสด ๆ ได้ด้วย

## 🛠️ เทคโนโลยี
Three.js (3D + Bloom) • PeerJS (WebRTC multiplayer + voice) • Web Audio • ไม่มีขั้นตอน build

โค้ด: `index.html` (หน้าเว็บ) + `css/game.css` + `js/*.js` — แผนที่โค้ดอยู่ใน `CODEMAP.md` สถานะงานล่าสุดอยู่ใน `HANDOFF.md` • ทดสอบในเครื่องต้องเปิดผ่านเซิร์ฟเวอร์: `python tools/serve.py 8765` แล้วเข้า http://localhost:8765 (เปิดไฟล์ตรง ๆ แบบ file:// ไม่ได้)
