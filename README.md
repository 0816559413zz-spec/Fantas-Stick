# ✦ Fantas Stick ✦

**▶ เล่นเลย: https://0816559413zz-spec.github.io/Fantas-Stick/**

เกมดวลเวทมนตร์ 3D มุมกล้องหลังไหล่แบบ Hogwarts Legacy — เล่นในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้ง

> โปรเจกต์แฟนเมดทำเล่นเองกับเพื่อน ไม่ได้ใช้เชิงพาณิชย์

## 🎮 โหมดเกม
- **Co-op ผ่านด่าน** (1–2 คน) — สู้ศัตรูเป็นคลื่นไปเรื่อยๆ เลือกพลังเสริมระหว่างด่าน บอสทุก 5 ด่าน
- **ดวล 1v1** — ชนะ 2 ใน 3 รอบ
- **FFA** (2–6 คน) — ใครได้ 10 kill ก่อนชนะ
- **ทีม สูงสุด 6v6** — ทีมไหนได้ 15 kill ก่อนชนะ
- **ห้องฝึก** — ลองคาถา เสกมอนสเตอร์ ปรับไม่มีคูลดาวน์ได้
- **ควิดดิช** — 2 ทีม บินแย่งบอลโยนเข้าห่วง
- **แข่งไม้กวาด** — บินลอดห่วงครบ 2 รอบ
- **แบทเทิลรอยัล** — เก็บคาถา วงหด คนสุดท้ายชนะ
- **หาลอร์ดโวลเดอมอร์** — ทำภารกิจ จับตัวโวลเดอมอร์ (แบบ Among Us)
- 🏰 โหมด **บุก/รับปราสาท** ยังอยู่ระหว่างออกแบบ (ยังเล่นไม่ได้) — ดู `designs/castle-gameplay-concept.md`

## 🗺️ แผนที่ (สุ่มทุกเกม)
- 🏰 **ลานปราสาท** — ยามค่ำคืน เทียนลอย คบเพลิง
- 🌲 **ป่ามืด** — ต้นไม้ หินโบราณ หิ่งห้อย และแมงมุมยักษ์!
- 🏟️ **สนามควิดดิช** — พระอาทิตย์ตก ห่วงประตู อัฒจันทร์ธงสีบ้าน
- ยังมีแผนที่อื่นอีกมาก (โถงใหญ่ ฮอกส์มี้ด ทะเลสาบ ทุ่งหญ้า ซากปรักหักพัง หุบเขา ฯลฯ) — ดูรายการใน `assets/maps/`

## ⬇️ ติดตั้ง / อัปเดตเกมในเครื่อง (`Update Game.bat`)
ใช้เมื่ออยากได้เกมทั้งโฟลเดอร์ในเครื่อง (เช่น ใช้ VFX Studio / สตอรี่บอร์ด / เล่นแบบไม่ผ่านเว็บ) — ถ้าแค่เล่น เปิดลิงก์ข้างบนได้เลย ล่าสุดเสมอ
- **เครื่องใหม่:** ดาวน์โหลดไฟล์ [`Update Game.bat`](https://github.com/0816559413zz-spec/Fantas-Stick/raw/main/Update%20Game.bat) ไปไว้ที่ไหนก็ได้ → ดับเบิลคลิก → เกมทั้งหมดจะลงในโฟลเดอร์ `Fantas-Stick` ข้าง ๆ ไฟล์
- **อัปเดต:** ดับเบิลคลิก `Update Game.bat` ในโฟลเดอร์เกม → ดึงเวอร์ชันล่าสุด บอกว่ามีอะไรเปลี่ยน แล้วเปิดเกมให้ (งานที่แก้ค้างในเครื่องไม่หาย)
- มี [Git](https://git-scm.com/download/win) จะเร็วกว่า (ไม่มีก็ได้ — จะดาวน์โหลด ZIP แทน) • มี [Python](https://www.python.org/downloads/) จะเปิดเกมในเครื่องให้ (ไม่มี = เปิดเกมออนไลน์)

## 👫 เล่นกับเพื่อน
1. เปิดเกมที่ **https://0816559413zz-spec.github.io/Fantas-Stick/** ด้วย Chrome / Edge
2. คนหนึ่งกด **🏰 สร้างห้องออนไลน์** → ได้รหัสห้อง 5 ตัว
3. เพื่อนใส่รหัส → กด **🚪 เข้าร่วม**
4. โฮสต์เลือกโหมด → **▶ เริ่มเกม**
5. กด **เปิดไมค์** มุมซ้ายบน แล้ว **กด V ค้าง** เพื่อพูด

ต้องต่ออินเทอร์เน็ตตอนสร้าง/เข้าห้อง (ใช้ WebRTC ผ่าน PeerJS) — ข้อมูลเกมและเสียงวิ่งตรงระหว่างเครื่อง

## ⌨️ ปุ่มควบคุม
| ปุ่ม | ทำอะไร |
|---|---|
| คลิกที่จอ | ล็อกเมาส์ (Esc = ปล่อย) |
| WASD / เมาส์ | เดิน / หมุนกล้องและเล็ง |
| คลิกซ้าย | ยิงเวท |
| คลิกขวาค้าง | โล่ (ยกตอนโดนพอดี = Parry สะท้อนกลับ) |
| Q / E / R / F | ลูกไฟ / สตัน / ผลัก / ดึง |
| Space | หลบ (ตอนบิน = ขึ้น) |
| X | เวทโบราณ (เมื่อเกจเต็ม) |
| B / C | ขึ้น-ลงไม้กวาด / บินต่ำลง |
| Tab / V / M | ตารางคะแนน / พูดไมค์ / เปิดปิดเพลง |

## 🛠️ เทคโนโลยี
Three.js (3D + Bloom) • PeerJS (WebRTC multiplayer + voice) • Web Audio

โค้ด: `index.html` (หน้าเว็บ) + `css/game.css` + `js/*.js` — แผนที่โค้ดอยู่ใน `CODEMAP.md` • ทดสอบในเครื่องต้องเปิดผ่านเซิร์ฟเวอร์ เช่น `python -m http.server 8765` แล้วเข้า http://localhost:8765 (เปิดไฟล์ตรงๆ แบบ file:// ไม่ได้)
