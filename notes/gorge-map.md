# แมพ gorge 🌲 หุบเขาหมอก (2026-11-18)

อ้างอิงภาพ: `designs/gorge_ref/reference.png` (หุบเขาสนหมอก ทางดินไปสะพานไม้มีหลังคา) • เทียบ: `designs/gorge_ref/compare.jpg`, แผ่นรวม `designs/gorge_ref/sheet.jpg`

## ไฟล์ / สร้างใหม่ยังไง
| ไฟล์ | หน้าที่ |
|---|---|
| `tools/gorge-assets.mjs` | สร้างโมเดลด้วยโค้ด → `assets/mapkit/gorge.glb` (28 ชิ้น `g_*`, วัสดุเดียวสีที่จุดยอด) + ลงทะเบียนใน `kit.json` (`user`, id `gorge/<ชื่อ>`) + `gorge.info.json` (ขนาดชิ้น ให้ตัวสร้างแมพใช้) |
| `tools/gorge-map.mjs` | สร้างต้นฉบับ `maps/build/gorge.json` (ภูมิประเทศ พื้นผิว สะพาน ของตกแต่ง จุดเกิด แสง/หมอก) ใช้ `mapbuild/model.js` |
| `tools/mb-export.js` | ส่งเข้าเกมจาก CLI: `node tools/headless.js --url "mapbuild.html?export=gorge" --js tools/mb-export.js --quiet` (ต้องรัน `python tools/serve.py`) |
| `tools/gorge-shots.js` / `gorge-look.js` / `gorge-walk.js` | ถ่ายภาพหลายมุม / เทียบค่าแสงหลายแบบ / ทดสอบเดินขึ้นสะพานและลอดใต้สะพาน |

ลำดับ: `node tools/gorge-assets.mjs && node tools/gorge-map.mjs` → export → `node tools/headless.js --game --url "index.html?nosw&playmap=gorge" --js tools/gorge-shots.js --w 1280 --h 640 --quiet` (ได้ `shots/gorge_sheet.jpg`)

## ผังแมพ (160×110 ม.)
- หุบเขาคดเคี้ยวเหนือ–ใต้ (`xc(z)` ใน gorge-map) พื้นหุบ ~0 ม. ตลิ่งตะวันตกชัน/สูง 8.8 ตะวันออกลาดกว่า 7.6 ที่ราบสูงเป็นป่า ปลายเหนือ/ใต้หุบยกขึ้นเป็นที่ราบสูง (ปิดหัวท้าย)
- **สะพานมีหลังคา** กลางแมพ (86,45) ยาว 28 ม. สูง 6.4 ม. ข้ามหุบ: พื้น = `floors[0]` (เดินข้ามได้ ลอดใต้ได้ ทดสอบแล้ว), ผนังล่างสูง 1.3 = `walls[]` (`base` 6.4 ไม่ขวางคนข้างล่าง), โครง/หลังคา = โมเดล `bridge_cov` (ไม่มีที่ชน)
- จุดเกิด: ทั่วไป 10 • แดง 3 (ใต้) • น้ำเงิน 3 (เหนือสะพาน) • โหมด ffa / duel / tdm / coop • `random:0` (ไม่อยู่ในรายการสุ่ม เลือกเองในล็อบบี้ — เปลี่ยนเป็น 1 ใน gorge-map ถ้าอยากให้สุ่ม)
- ของ ~800 ชิ้น: สน 150 (ที่ชนที่ลำต้น) + สนไกลเบา 80 + วงนอกแมพ 130 (ไม่มีที่ชน) • ต้นใบเหลืองจาง 12 • ลำเปลือย 22 • หินมอส/ผา ~60 • หินเล็ก 200 • ขอน/ตอ 35 • พุ่ม/เฟิร์น ~100 • ที่ชนรวมราว 200 วง

## แสง / หมอก (ให้ตรงภาพ)
- ไฟล์แมพมีฟิลด์ใหม่ (ไม่มีช่องใน Map Builder แก้ไฟล์ต้นฉบับ/ตัวสร้างตรง ๆ): `look:"gorge"` = พรีเซ็ต Look `LOOK.P.gorge` (js/74-look.js: ACES, IBL เบา, หมอกลอยต่ำ, ลำแสง) • `lt` = `{hemi:[ฟ้า,พื้น,แรง], sun:[สี,แรง,[x,y,z]], sky:'#สี' (ฟ้าครึ้มสีเดียว), exp}` (js/28 `buildFileMap`) • `fog:['#c3cac4',30,270]`
- พื้นผิวใหม่ใน `mapbuild/model.js` SURF (ต่อท้าย ห้ามแทรก): 16 moss, 17 litter, 18 gravel, 19 duff, 20 trail • สีเลือกให้ "ไม่เขียว" ตามสูตรหญ้า 3D ของ js/50 (ไม่งั้นปลูกหญ้าทั้งตลิ่ง)
- ⚠ ปรับค่าแสงสดได้ที่ tune.html หมวด 🌗 Look → `gorge` หรือรัน `gorge-look.js` เทียบหลายแบบ
