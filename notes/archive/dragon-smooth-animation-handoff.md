# ส่งต่อวิธีทำแอนิเมชันมังกรน้ำให้ลื่น

ผู้ใช้ขอเก็บวิธีทำไว้ให้เซสชันอื่นนำหลักการไปใช้ โดยเฉพาะงาน Nature ที่กำลังออกแบบกับ Claude ตัวอย่างจริงอยู่ `js/70-water-dragon.js` (runtime) และ `tools/water-dragon-freecruise-preview.js` (ต้นแบบ Studio) ประวัติการแก้และ feedback อยู่ `notes/archive/water-dragon-preview-history-2026-11-01.md` ข้อมูลนี้เป็นวิธีทำ ไม่ได้หมายความว่าทุกการเคลื่อนไหวของ Nature ต้องเหมือนมังกร

## หลักที่ทำให้ดูเป็นสิ่งมีชีวิต

1. **ออกแบบเส้นทางให้หัวบินได้จริงก่อน** เส้นทางเริ่มจากใต้วงเวท วนขึ้น โค้งกว้างลง แล้วค่อยบินช้าไปข้างหน้า จุดต่อของเส้นโค้งต้องต่อทั้งตำแหน่งและทิศทางสัมผัส (tangent) เพื่อไม่ให้หัวเปลี่ยนทิศฉับพลัน เลือกจุดพักตามทางที่ดูเป็นธรรมชาติ ไม่ฝืนบังคับหัวให้เข้าจุดหรือรูปร่าง S ที่กำหนด
2. **ให้ตำแหน่งและทิศหัวใช้ค่าระยะบนเส้นทางเดียวกัน** ใน `shape(t)` ใช้ `filtered` กับ `PA(filtered)` และ `TA(filtered)` จึงหันตามทิศบินจริง ไม่ใช้ตำแหน่งที่วิ่งเร็วกับมุมที่ lerp ไปหาเป้าคนละจังหวะ ตัวกรองใช้ `1 - exp(-dt * 18)` เพื่อให้การตอบสนองอิงเวลาจริง; ปรับค่าตามงาน อย่าคัดลอกตัวเลขโดยไม่ดู
3. **เร็วขึ้นได้โดยยังใช้เวลาเท่าเดิม:** เพิ่มระยะ/ความโค้งที่บินในช่วงเดิม ไม่ใช่แค่ตัดเวลาทิ้ง ใน runtime `progress(t)` เริ่มเร่ง บินเร็ว แล้วค่อยเบรกก่อนเข้าช่วงบินช้า (`fastDuration=1.1`, `brakeDuration=1.65`, `hoverSpeed=.65`; intro ประมาณ 3.1 วิ) หัวยังเคลื่อนไหวต่อเมื่อเข้า standby แทนการล็อกหยุดทันที
4. **หัวนำ ลำตัวไหลตาม หางตามทีหลัง:** แบ่งตัวเป็นวงย่อยตามความยาว แต่ละวงอ่านทิศทางจากตำแหน่งย้อนหลังตามระยะบนเส้นทาง (`advance - distance`) แล้วไล่สร้างแนวตัวจากหัวไปหาง มีการเกลี่ยทิศด้วย quaternion และจำกัดมุมงอระหว่างวงติดกัน ปลายหาง 5 เมตรสุดท้ายสะบัดเร็วเป็นพิเศษ (`tipHz=3.4`) และไม่ส่งแรงกลับไปหมุนหัว
5. **จุดเกิดต้องผ่านทางเดียวกัน:** ช่วงใกล้พื้นให้ส่วนตัวตามตำแหน่งย้อนหลังของเส้นทางจริง แล้วค่อย blend ออกเป็นการพลิ้วอิสระเมื่อพ้นพื้น หางจึงไม่โผล่มาคนละที่; ตอนพุ่งลง blend กลับตามทางอีกครั้ง
6. **กันการพลิกตัว:** สร้างกรอบหัวจากทิศบินและแนวดิ่งเมื่อทำได้ จากนั้นค่อยส่งกรอบไปตามทิศของแต่ละวงด้วย quaternion และจัดให้ตั้งฉาก ผลคือครีบ แขน ผิว และหัวเกาะกับตัวโดยไม่เกิดการพลิกม้วนกะทันหัน

## เมื่อเปลี่ยนจากบินรอเป็นพุ่ง

`dive()` เริ่มทางใหม่จากตำแหน่งและ tangent ปัจจุบัน (`PA/TA`), สร้างวงขึ้นและโค้งลงต่อเนื่องไปเป้า ใช้ตารางระยะ/ความเร็วคำนวณล่วงหน้าเพื่อกำหนดหัวถึงพื้นตามจังหวะสกิล แล้วให้ลำตัวไหลตาม ความเร็วขึ้นกับระยะและช่วงโค้ง ไม่ใช่สั่งหมุนหัวเข้าหาเป้าทันที ตัวค่อยยืดด้วย smoothstep ระหว่างพุ่งและคลื่นลำตัวจางใกล้พื้น อ่านโค้ดจริงก่อนปรับ เพราะ runtime ต้องตรงเวลาดาเมจด้วย

## วงรอบรีวิวกับผู้ใช้

- อ่านภาพอ้างอิงและฟัง feedback ก่อน ทดลองใน VFX Studio ก่อนผูกเข้าเกมถ้างานนั้นยังอยู่ช่วงออกแบบ
- ส่งภาพนิ่งจากตัวอย่างจริงเพื่อดูทรง แล้วส่ง GIF ที่เห็นทั้งการออกตัว โค้ง ชะลอ และช่วงพัก ให้ดูในแชทโดยตรง ตรวจภาพเองก่อนส่ง
- แก้จุดที่ผู้ใช้ระบุและเก็บส่วนที่รับแล้วไว้ เช่น อย่าเปลี่ยนทางบินทั้งชุดเพียงเพราะกำลังแก้หน้า
- ตรวจการเปลี่ยนทิศทีละเฟรม ทั้งหัว คอ ลำตัวและหาง รวมถึงรอยต่อทาง/ตอนเปลี่ยนสถานะ ตรวจมุมกล้องและอัตราเฟรมต่างกัน; ตัวเลขมุมหรือไม่มี error ช่วยจับบั๊ก แต่ใช้แทนการดู GIF ไม่ได้
- ปัญหาที่ผู้ใช้เคยเจอคือหัวหักเพื่อฝืนเข้าที่ หางถูกล็อกท่า และตัวหักเมื่อเปลี่ยนจากบินเป็น standby วิธีแก้คือจัดเส้นทางและความเร็วใหม่ก่อน ไม่ใช่เพิ่ม smoothing ทับจุดหักอย่างเดียว

## นำหลักไปใช้กับ Nature

`designs/nature.md` เป็นร่างที่ผู้ใช้กำลังออกแบบกับ Claude: BA คือแส้หนามออกจากไม้เฉพาะตอนตวัด ซ้าย–ขวาสลับ และต้องพลิ้วเหมือนแส้จริง อาจใช้หลัก **โคนถูกมือพา → ลำตัวโค้งตาม → ปลายหน่วงและสะบัดตามทีหลัง** โดยออกแบบการเหวี่ยงให้เข้ากับแส้ ไม่ยกเส้นทางบินหรือค่ามังกรไปใช้ตรง ๆ ตัวเลข/สกิลและจังหวะอื่นให้ยึดร่างล่าสุดและคุยกับผู้ใช้ก่อนตัดสินใจ
