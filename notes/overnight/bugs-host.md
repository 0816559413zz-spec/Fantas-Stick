# หาบัคฝั่งโฮสต์ (bugh) — 2026-10-22 คืน

อ่านโค้ด js/03–15 (คาถา, สถานะ, เครือข่าย, โหมด) แล้วแก้บัคที่เจอจริง ทุกข้อทดสอบแบบ headless แล้ว ไม่มี error

## บัคที่แก้แล้ว (ผู้เล่นจะเห็นอะไร → แก้ยังไง)
- **โหมดโวลเดอมอร์: เกมค้างทั้งห้อง** — ถ้าคนที่ถูกโหวตออกจากห้องไประหว่างประชุม พอนับคะแนนเสร็จ โฮสต์ error ทุกเฟรม เกมหยุดนิ่งหมดทุกคน → ตอนนี้ขึ้นว่า "ไม่มีใครถูกโหวตออก (คนที่ถูกโหวตออกจากห้องไปแล้ว)" แล้วเล่นต่อได้ (`meetTick` ใน js/15)
- **สายน้ำแข็ง: ตายตอนกระโดดฟาดลงพื้น แล้วเกิดใหม่ฟันดาบไม่ได้** — ค่า "กำลังฟาด" ค้างไว้ ต้องกระโดดก่อนถึงจะฟันได้ (และพอลงพื้นจะฟาดฟรี 30–50 ดาเมจ) → ล้างค่านี้ตอนเกิดใหม่/ตอนล้ม (`resetBody` js/11, `playerDown` js/12)
- **ห้องฝึก: เปลี่ยนสายกลางท่า แล้วตัวค้าง** — เช่นเปลี่ยนสายตอนใช้อัลติดิน Wrath = ลอยค้างบนฟ้าเดินไม่ได้ตลอด, ตอนชาร์จ Auger = เดินช้า 85% ตลอด, ตอนเล็ง Railgun = เดินไม่ได้, ร่างเทพสายฟ้าค้าง → เปลี่ยนสายกลางเกมแล้วล้างท่าค้างของสายเก่าทั้งหมด (`setKit` + `pathReset` ใหม่ ใน js/03)
- **Co-op: ล้มตอนกำลังใช้ Dragonfall / ดีดนิ้ว / Glacier Rend / ชาร์จพุ่งไฟ** — คนล้มยังปล่อยท่าได้ หรือท่าค้างไว้แล้วออกเองทันทีที่ถูกชุบ → ล้างท่าที่ง้างอยู่ตอนล้ม (`playerDown`)
- **Co-op ขึ้นชั้นใหม่ / ดวลขึ้นรอบใหม่: วงเวท/ฟ้าผ่าหน่วง/พื้นน้ำแข็งที่มองไม่เห็นยังทำดาเมจ** — ของในสนามหยุดนิ่งช่วงเลือกบัฟ/นับถอยหลัง แล้วกลับมาทำงานต่อทั้งที่ภาพบนจอหายไปแล้ว → ล้างของในสนามตอนขึ้นชั้น/ขึ้นรอบ (`clearField` ใหม่ ใน js/14) — กำแพง/เสาสายดินไม่ล้าง (ภาพซิงก์ตรงกันอยู่แล้ว)
- **ลูกไฟวิญญาณ (สายไฟ) ติดข้ามเกม** — จบเกมมีลูกไฟหมุนรอบตัวอยู่ เกมใหม่ยังมีอยู่ → เริ่มเกมใหม่ = 0 (`freshStats`)
- **กันข้อมูลแปลก ๆ จากเครือข่าย** (เพื่อนที่ใช้เวอร์ชันเก่า/ข้อมูลเสีย):
  - ส่ง hello ซ้ำ = ผู้เล่นคนเดิมถูกเพิ่ม 2 ครั้ง (ตัวเดินเร็ว 2 เท่า) → ไม่เพิ่มซ้ำ
  - ค่าเล็งที่ไม่ใช่ตัวเลข → ตัดทิ้ง (เดิมทำให้มุมหันเป็น NaN)
  - เมนูทดลองเสกมอนสเตอร์ชื่อแปลก (เช่น "constructor") → ไม่เสก / โหวตชื่อที่ไม่มีจริง → ไม่รับ
- **ตาข่ายกันเกมค้าง**: ถ้ามีบัคหลุดใน `hostTick` อีก เกมจะไม่หยุดทั้งห้อง (ยังส่ง snapshot ต่อ + พิมพ์ error ใน console ทุก ~10 วิ)
