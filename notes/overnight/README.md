## 1–2. Frost: ร่ายคาถาให้ดาบฟันเอง + อัลติดาบ 3 เล่ม ✅
- โหมดประชิด: **ถือไม้กายสิทธิ์ตลอด** — ดาบน้ำแข็ง (หรือขวานตอน Frostforge) **ลอยอยู่ข้างขวาหน้า แล้วฟันเอง** ตามที่เราโบกไม้ มีเส้นด้ายเวทบาง ๆ จากปลายไม้ไปที่ด้าม
  - จังหวะ 1 กวาดขวา→ซ้าย • จังหวะ 2 ซ้าย→ขวา • จังหวะ 3 ลอยขึ้นเหนือหัวแล้วสับลงพื้น (ตรงจุดระเบิดเดิม)
  - ขวาน: ง้างนานกว่า วงใหญ่กว่า ดูหนักกว่า • Glacier Rend ประชิด: อาวุธลอยขึ้นเหนือหัวตอนชาร์จ แล้วสับลงปล่อยคลื่น • ฟาดจากที่สูง: อาวุธพุ่งนำลงพื้น
  - **ระยะ/ดาเมจ/จังหวะตีเท่าเดิม** (แก้แค่ภาพ) — ปลายใบไปถึง ~5 ม. + รอยฟันเดิมยาวถึงระยะจริง 6 ม. (ขวาน 8 ม.)
- อัลติ Mirror Legion: **ไม่มีร่างแยกแล้ว** → มี **ดาบ/ขวานลอย 3 เล่ม** (เล่มหลัก + 2 เล่มซ้าย/ขวา ตรงที่ร่างแยกเคยยืน) ฟันพร้อมกันทุกจังหวะ • ตอนเปิดพุ่งไปพร้อมฟันไป-กลับ 3 ครั้ง • จบแล้ว 2 เล่มเสริมร้าวแตกเป็นเกล็ด • ไอคอนใหม่ = ดาบ 3 เล่ม • คำอธิบายสกิลแก้แล้ว
- 🤔 **Claude ตัดสินใจเอง:** "ดาบสามเล่ม" = รวม 3 เล่ม (เล่มเดิม + เพิ่ม 2) เพราะฝั่งเกมฟันซ้ำแค่ 2 จุด (เล่มละ 50%) — ถ้าอยากได้ 4 เล่ม (เพิ่ม 3) บอกได้ แต่ต้องแก้ตัวเลขดาเมจ (ให้คนทำบาลานซ์ตัดสิน)
- 🤔 เอาเสี้ยวน้ำแข็งใหญ่ 2 ข้างตอนพุ่งอัลติออก (เดิมลอยรอบกล้องจนจอขาว) — อาวุธ 3 เล่มฟันให้เห็นแทน
- 🐞 แก้บั๊กเดิม: ตอนเปลี่ยนจังหวะคอมโบ (เช่น 2→3) แขน/ตัวกระตุกแรงมาก 1 เฟรม
- ❓ ให้ลองเล่น: ดาบลอยอยู่ตำแหน่งนี้โอเคไหม (ข้างขวาหน้า ระดับอก) / อยากให้ใหญ่หรือเล็กกว่านี้ / เส้นด้ายเวทชัดเกินหรือจางเกิน

## 3. ท่าร่ายคาถาแบบ Harry Potter (ยิงปกติทุกสาย) ✅
- ทุกครั้งที่ยิง ตัวละครจะ **ฟาดไม้แบบนักเวทในหนัง** สลับ 3 ท่า: ฟันเฉียงจากบนขวา / วนข้อมือแล้วสะบัด (swish & flick) / แทงตรง — ตัวหันไหล่ขวาเข้าหาเป้า มือซ้ายกางทรงตัว ยืนอยู่จะก้าวขาเล็กน้อย + หางแสงบาง ๆ จากปลายไม้
- หลังร่าย 2 วิ จะ **ยืนตั้งการ์ด** ยกไม้ไว้หน้าไหล่แบบดวลในหนัง
- Pyro: ชาร์จลูกไฟ = ง้างไม้ข้างไหล่ มือซ้ายยื่นประคองไฟ ยิ่งเต็มยิ่งสั่น • ปล่อย = พุ่งแทงแรง
- Storm: ลำแสงกดค้าง = ท่าดวลลำแสงแบบแฮร์รี่ vs โวลเดอมอร์ (แขนเกร็ง มือซ้ายจับข้อมือ เอนหลัง สั่น) • สายฟ้าสามเหลี่ยม = ฟาดไม้จากเหนือหัว
- Frost (ยิงไกล): แทง/ฟันสลับ • ก้อนน้ำแข็ง = พุ่งแทงแรง • Earth: สั่ง Stand ต่อย = ชี้ไม้/หมัดไปทางเป้า
- 🤔 ลูกเวทออกทันทีที่กด (ฝั่งเกม) → ท่าง้างจึงสั้นมาก (0.06 วิ) แล้วฟาดทันที ไม่งั้นลูกเวทออกก่อนไม้ฟาด
- ❓ ให้ลองเล่น: ท่าใหญ่/เร็วพอไหม อยากได้ท่าไหนเพิ่ม (เช่น วาดวงกลมก่อนยิง)
