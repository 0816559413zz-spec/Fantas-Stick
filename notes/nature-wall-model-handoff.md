# กำแพงไม้ Nature — ร่าง Model ก่อนอัลติ

## รุ่นที่ผู้ใช้รับ — v1 จาก r7

ผู้ใช้ตอบรับและสั่ง "save it v1" เก็บโมเดลแยกที่ `assets/fx/mesh/nature_wood_wall_v1.mesh.json` ทุกparts/วัสดุตรงr7ที่รับ มีตัวสร้างfreeze `tools/nature-wood-wall-v1-gen.py` และภาพติดgitที่ `designs/nature_vfx/wall_v1_crown.jpg`, `wall_v1_overview.jpg`, `wall_v1_arc.jpg` ห้ามแก้v1โดยอัตโนมัติเพื่อทดลองงานอื่น ใช้studyหรือชื่อรุ่นใหม่แทน

นี่คือการรับภาพModelv1 ไม่ใช่อนุมัติใส่เกม/เลือกตัวเลข/ทำอนิเมชันไฟหรือการงอก งานถัดไปผู้ใช้เลือกต้นไม้อัลติ Nature ตามเรฟ Loki พร้อมภาพหลายมุม และขอทำงานเพิ่มได้เองระหว่างนอน

ส่วนร7ด้านล่างเป็นที่มาของv1 คำว่า"รอรีวิว"ในประวัติไม่ย้อนคำตอบรับล่าสุดนี้

## r7 ปัจจุบัน — ใบแนบข้อไม้และหนามตามภาพอ้างอิง

- ผู้ใช้ไม่รับช่อใบสูงของr6 ย้ำภาพ Groot เดิมว่ามีหนามบนยอดและกลางค่อนไปด้านบน และชี้รูปแบบการวางใบตามภาพ ไม่ทำใบเป็นต้นกล้าตั้งเรียงต่อ
- เอาช่อสูงออก ใช้กลุ่มใบเตี้ยแนบกับไม้: กลุ่มห้าใบกับกลุ่มสามใบวางตามจุดที่กิ่งขึ้นถึงยอด มีก้านเลื้อยสั้นร่วมกัน ใบห้อยแนบหน้าไม้ช่วงบนตามข้อกิ่ง ไม่ใช่ใบเดี่ยวสุ่มทิศทางทั่วแผง
- เพิ่มหนามไม้9ชิ้นบนยอดและ6ชิ้นตามข้อกิ่งช่วงบน โคนหนาฝังกับไม้แล้วโค้งเรียว ไม่เปลี่ยนทุกท่อนไม้ให้เป็นรั้วแหลม รูปร่าง/จำนวนเป็นร่างรอรีวิว ไม่ใช่ตัวเลขเกม
- ไม่เพิ่มดาเมจ พิษ สะท้อน หรือ collider จากหนาม ราก/ความโค้ง/วัสดุกำแพงคงทิศทางr5
- โมเดล358ชิ้น/28,250triจริง มีwarningประมาณงบpolyตามเดิม แต่FX/JSตรวจผ่าน ไม่มีpage errorsในcapture
- ภาพ `shots/nature_wood_wall_r7_crown.jpg` / `_oblique.jpg` และ `nature_wood_wall_r7_dark_*` เปิดModel `&mview=mat&rev=7` ยังเป็นModelรอรีวิว ไม่ทำGIF/ไฟ/งอก/เกม/commit/push

## r5 ปัจจุบัน — ผิวไม้ รากแตกแขนง กำแพงโค้ง และใบเป็นช่อ

- ผู้ใช้บอกว่า r4 ดีขึ้นมากแต่ยังไม่ชอบtexture/ใบ และขอให้รากแตกแขนงออกจากรากใหญ่เพิ่ม กำแพงโค้งเข้าหาฝั่งผู้เล่นเล็กน้อย ใบยอดไม่เหมือนassetทรงเดียวสุ่มซ้ำ ไม่ย้อนรื้อกลับเป็นโครงโปร่งr3
- ทุกชิ้นส่วน (ผิวไม้ กิ่ง ราก ก้านใบ ใบ) โค้งด้วย arc เดียวกัน ปลายคืนเข้าฝั่ง local-Z ลบ = ฝั่งผู้ร่ายเมื่อวางกำแพงข้างหน้า รัศมีต้นแบบ18ม. ปลายเยื้องราว0.8ม. ยังไม่ใช่ตัวเลขที่ล็อกหรือcolliderเกม
- แต่ละรากหลักมีกิ่งย่อยแยกจากช่วงต้นและกลาง ไม่แตกเฉพาะปลาย บางกิ่งย่อยมีรากเล็กแยกต่อ ทุกเส้นอยู่ระดับพื้น ไม่เพิ่มสถานะเกมจากราก
- ใบเปลี่ยนเป็นแผ่นโค้งพับกลาง มีผิวบางสองด้าน หลายสัดส่วน อยู่บนก้านช่อร่วม มีคู่ใบ/ใบปลายร่วมกันรวม160ใบ มี40ช่อทั้งยอด ข้อกิ่ง และฐาน รากช่อยอดยึดผิวสูงจริงจากfield ไม่ลอยตามความสูงค่าคงที่
- เพิ่ม file `bark:true` แบบopt-in สำหรับsolid model, ใช้ `fxModelBark` ร่วมModel/runtime: ร่องเสี้ยนยาวขาดช่วง ลายผิวต่างเฉด และreliefละเอียด วัสดุด้าน ใบที่มีสีเขียวข้ามการแต่งผิวไม้ ค่าเริ่มfalseไม่เปลี่ยนวัสดุเก่า เพิ่มschemaของpoly.uvให้ตรงกับruntimeที่รองรับแล้ว
- ภาพปัจจุบัน `shots/nature_wood_wall_r5_oblique.jpg`, `_arc.jpg`, `_roots.jpg`, `_crown.jpg`; ฉากมืด `nature_wood_wall_r5_dark_*`
- โมเดล377ชิ้น/29,296สามเหลี่ยมจริง Checkerประมาณ42,172จึงยังเตือน1รายการงบpoly แต่ไม่มีerror การตรวจJSและGPU shader compile (เปิดcheckShaderErrorsในcapture) ผ่าน ไม่มีpage errors
- Integration `tools/check-model-part-colours.js` ผ่าน: geometry2legacyไม่เปลี่ยน, palette tokens, Model/runtime default+tint+grow มีสี/smooth/bark และlegacy Modelยังใช้flat lighting/ไม่มีbark Shaderใหม่ไม่อัตโนมัติไปทับโมเดลอื่น
- ยังรอผู้ใช้รีวิว ไม่ทำGIF/ไฟไหม้/งอก/เกม/commit/push รอบนี้ ตัวเลขHP/CD/ระยะเวลา/การวางเกมจริงไม่เปลี่ยน

สร้าง/จับภาพด้วยgeneratorและcaptureเดิม ส่วนสคริปต์เช็กใช้URLเริ่มFXตามตัวอย่าง r3 ด้านล่าง เปิดดูสดในModelใช้ `&mview=mat&rev=5` เพื่อเห็นวัสดุใหม่

## r4 ปัจจุบัน — ผู้ใช้ไม่รับ r3 เพราะยังไม่เหมือนกำแพง

- ผู้ใช้ย้ำ reference Groot เดิม: แผงต้องแน่น อ่านเป็นกำแพง ไม่ใช่โครงเถาช่องโหว่ใหญ่ รากต้องเล็กลงแต่แผ่บนพื้นมากขึ้น ใบบนยอดมากขึ้น ร่าง r3 ไม่ผ่าน ห้ามอ้างว่าเป็นแบบที่ผู้ใช้รับ
- r4 เพิ่มเนื้อไม้กลางแผง ปิดช่องใหญ่ กิ่งคดนูนเชื่อม/แตกแขนงทั้งผิวและหลายระดับ ใช้โครงกิ่งต่างทิศ แยกเฉดไม้เพื่อเห็นการซ้อน ไม่ย้อนเป็นแท่งรั้วแหลม
- ร่างล่าสุด648ชิ้น รวม29,854สามเหลี่ยมจริง; checkerประมาณ49,350และเตือนตามวิธีประมาณpoly แต่ไม่มีerror ภาพตรวจทั้งภาพรวมและราก มีเพียงวัสดุสีพื้น/กิ่งนูน รายละเอียดผิวไม้ยังไม่ใช่งาน texture สุดท้าย
- เอารากทรงขาหนาที่ผู้ใช้ไม่ชอบออก ใช้รากเล็กระดับพื้น หลายเส้นคดแผ่พร้อมรากแยกปลาย ใบเล็กจำนวนมากเป็นกลุ่มบนยอดและตามข้อกิ่ง
- ภาพ `shots/nature_wood_wall_r4_front.jpg`, `_oblique.jpg`, `_roots.jpg` ใช้สคริปต์เดิม URLเริ่ม `studio.html?fx=start/hit&at=self&map=test` แล้วสลับ Model ในสคริปต์ ไม่ใช้ภาพ r3 แทนร่างปัจจุบัน
- ยังเป็น Model preview ยังไม่ทำ GIF/งอก/ไฟ/เกม ไม่ commit/push ตัวเลขสกิล/ความยาวเกมจริงไม่เปลี่ยน รายละเอียดวัสดุยังเป็นสีพื้นกับเรขาคณิต ไม่อ้างว่าเหมือน texture ของเกมอ้างอิงแล้ว

## r3 ใหม่กว่า r2 — โครงไม้เชื่อมกันตามภาพผู้ใช้

- Reference ล่าสุดเก็บ `designs/nature_ref/wood_wall_groot_ref.png` ผู้ใช้ชี้ว่ากำแพงต้องเป็นเนื้อไม้แตกแขนงเชื่อมกัน ไม่ใช่ท่อนไม้ตั้งเรียง ร่างเก่า r1/r2 ไม่ตรง ยอดต้องโค้งวกตามภาพ ไม่ใช่ปลายแหลม และรากต้องทอดแผ่บนพื้นมากขึ้น
- รื้อ generator เป็น branching skeleton แล้วใช้ implicit smooth union + numpy surface nets สร้าง `fused_living_wood` poly ผิวเดียว เก็บเฉพาะ connected component หลัก ทรงหลักมีโพรงและกิ่งวกเชื่อมต่อ ราก/เส้นเปลือก/ใบยังแก้แยกชิ้นได้ ไม่ย้อนใช้ vertical fence
- ยอดเป็นกิ่งคดโค้งหลายช่วงต่อกลับเข้าตัว รากหลักโค้งลงสู่พื้นแล้วมี rootlets/forks/spreading roots ทอดออกไป ใบตามข้อกิ่งและราก ไม่มี collider/slow/สถานะใหม่จากรูปทรงเหล่านี้
- โมเดลปัจจุบัน241ชิ้นส่วน 29,036สามเหลี่ยมจริง วัดด้วย Studio; checkerประมาณ43,972 เพราะประมาณ poly จากจำนวนจุดบนหน้า จึงมี warningงบโมเดล1รายการแต่ไม่มี error (ไม่อ้างว่า lintว่าง)
- เพิ่ม `smooth:true` ระดับไฟล์โมเดลแบบ opt-in ให้ solid material ใช้ vertex normals ใน Model/runtime; ค่าเริ่ม false จึงไม่เปลี่ยนวัสดุของเก่า สีชิ้นส่วนและ smooth lighting ผ่าน integration check พร้อม legacy geometry2แบบ/runtime default+tint+grow/palette token
- ตัวสร้างต้องใช้ numpy โมเดลยังเป็นร่าง Model ไม่ผูกเกม ไม่ทำ GIF/ไฟ/งอก ไม่ commit/push และยังรอผู้ใช้รีวิว
- ภาพใหม่: `shots/nature_wood_wall_r3_front.jpg`, `_oblique.jpg`, `_roots.jpg` ฉากมืดชื่อ `nature_wood_wall_r3_dark_*`
- จับภาพด้วย URL เริ่มแท็บ FX ก่อนแล้วสลับ Model ในสคริปต์ ลดการแข่งกับ async URL selection:

```powershell
python tools/nature-wood-wall-gen.py
node tools/fx-check.js
node tools/headless.js --url "studio.html?fx=start/hit&at=self&map=test" --js tools/capture-nature-wood-wall.js --w 1500 --h 950 --timeout 180 --quiet
node tools/headless.js --url "studio.html?fx=start/hit&at=self&map=test" --js tools/check-model-part-colours.js --timeout 180 --quiet
```

ดู/แก้จริงใน Model: `studio.html?mesh=nature_wood_wall_study&at=front&map=test&cam=front&dist=14&mview=mat` ใช้ `&rev=3` เพื่อเปิดภาพใหม่เมื่อ browser เก่าแสดงรุ่นก่อน

## รอบ r2 — คำแก้ล่าสุดของผู้ใช้

- ผู้ใช้ขอให้ยาวขึ้น กิ่งคาดยังเชื่อมกันแต่เลิกแพตเทิร์นเฉียงซ้ำ รากยกพ้นพื้นแล้วแผ่รอบฐานแบบรากต้นไม้ มีใบเขียวแทรก
- Generator ปรับความกว้างต้นแบบจาก~7.2เป็น~10.6ม. ความสูงเดิม ใส่กิ่งพาดยาวหลายทิศ/หลายระดับกับกิ่งแยก รากโค้งแผ่ทั้งสองด้านและแตกแขนง ใบ86ชิ้นตามซอกและข้อกิ่ง ร่างรอผู้ใช้รีวิว ไม่ใช่ความยาวที่ล็อกแล้ว
- โมเดล249ชิ้นส่วน รวม22,410สามเหลี่ยม แสดงวัสดุไม้สีน้ำตาลต่างเฉดและใบเขียวใน Model ได้แล้ว ใช้ `&mview=mat` เมื่อเปิด URL ให้เห็นสีโดยตรง
- เพิ่มสีชิ้นส่วน `col` แบบ opt-in ใน recipe → geometry vertex colours และ solid material ของ Model/runtime เฉพาะโมเดลที่ระบุสี โมเดลเก่าไม่เพิ่ม attribute สีและไม่เปลี่ยนวัสดุ Clay ยังดูทรงแบบเดิมได้ Shader/custom material อื่นไม่ได้เพิ่มการรองรับสีในรอบนี้
- ตรวจ `tools/check-model-part-colours.js`: geometry/index/normal/uv/aPiv/aOrd ของโมเดลเก่า2ชนิดเหมือนเดิมเมื่อเพิ่มสีขาว สีเขียว/ชิ้นไม่ระบุสี/ชิ้นซ่อนถูกต้อง และ runtime default/tint/grow เก็บสีได้ ไม่มี page errors
- ภาพใหม่ `shots/nature_wood_wall_r2_front.jpg`, `_oblique.jpg`, `_roots.jpg`; ฉากมืดใช้ชื่อ `nature_wood_wall_r2_dark_*` สคริปต์เดิมสร้างภาพเหล่านี้แทนชื่อร่างแรก ยังไม่ทำ GIF/ไฟไหม้/ท่างอก/ผูกเกม หรือcommit/push

รายละเอียดด้านล่างเป็นร่างแรกเพื่อดูประวัติ ไม่ใช้แทน r2

ผู้ใช้ให้เริ่มกำแพงไม้ก่อนต้นไม้อัลติ (2026-11-06) รอบนี้ทำโมเดลใน VFX Studio เท่านั้น ไม่ผูกเกม ไม่ทำไฟไหม้/แอนิเมชันงอก ไม่แก้ collision/host และไม่ commit/push อัตโนมัติ

- โมเดล `assets/fx/mesh/nature_wood_wall_study.mesh.json`: ไม้หนาหลายท่อนโค้งต่างกัน กิ่งเฉียงเกี่ยวแผง ผิวมีสันเปลือก รากสั้นแผ่ทั้งสองด้าน

- 105 ชิ้นส่วนแก้ใน Model ได้; รวม21,088สามเหลี่ยม ยังเป็นร่างรูปทรง ไม่รับรองว่าเป็นโมเดลสุดท้ายหรือ optimized แล้ว
- สีดินปั้นใช้ดูทรง ยังไม่ลงวัสดุไม้/ใบ/ไฟจริง ภาพมีตัวละครจริงยืนเทียบ ขยับโมเดลไปด้านข้างเฉพาะการจับภาพ ไม่เปลี่ยนตำแหน่งใน recipe
- รูปทรงยังรอผู้ใช้รีวิว อย่าถือว่าคำสั่งให้ทำโมเดลแปลว่ารับรูปร่างแล้ว
