## 1. เอาอะไรจาก Overwatch และ VALORANT

| เอามาจาก | สิ่งที่เอามา | ใช้ในเกมเรายังไง |
|---|---|---|
| Overwatch | บุกเป็นช่วง ๆ จุดเกิดขยับตามแนวรบ | ตรงกับแกน 3 จุดและช่วงถอยร่น 20 วิ ที่มีอยู่แล้ว |
| Overwatch | **ที่สูง (high ground)** ทุกไฟต์ ใครยึดได้ได้เปรียบ | ระเบียง กำแพงเดิน หอ ให้ทั้งสองฝ่ายแย่งกัน |
| Overwatch | ทางเข้าแคบ (choke) มีทางอ้อมหลายทาง | ทุกช่วงมีทางหลัก ทางอ้อม และทางสูง |
| Overwatch | จุดฮีลประจำตำแหน่ง | ตรงกับ "จุดฮีลในแผนที่" ที่ตกลงหลักการไว้แล้ว |
| Overwatch | ผลักศัตรูชนกำแพงหรือตกขอบได้ประโยชน์ | สายดิน (ผลักชนของแข็ง) และสายลม (Dash ผลักชนกำแพง) ได้ใช้เต็มที่ |
| VALORANT | **3 เลน** ชัดเจน (ซ้าย / กลาง / ขวา) และการคุม "กลาง" | แต่ละช่วงแบ่งเป็น 3 เส้นทาง และมีทางเชื่อมระหว่างเลน |
| VALORANT | รูปทรงเรียบ อ่านง่าย ของบังวางตั้งใจ ไม่รก | ในเลนต่อสู้ใช้ของบังชิ้นใหญ่ที่อ่านทรงออก ของประดับไว้ขอบนอก |
| VALORANT | ทุกจุดมีชื่อเรียก (callout) | ตั้งชื่อทุกห้อง ทุกมุม ให้คุยกันในทีมได้ (ดูข้อ 6) |
| VALORANT | มุมสำหรับใช้สกิล เช่น จุดวางกำแพง จุดโยน | ออกแบบจุดให้สกิลวาง/โยนได้มีผล เช่น ประตูที่ Ring of Embers ปิดได้พอดี |
| VALORANT | ระยะยิงไกลมีน้อย ส่วนใหญ่ปะทะระยะกลาง | ให้มีแนวยาว ~50 ม. แค่ 1–2 เส้นต่อช่วง ที่เหลือเป็นระยะกลาง |

**สิ่งที่ไม่เอา:** ระบบซื้อของและโหมดวางระเบิดของ VALORANT, จังหวะ "ตายแล้วรอจบรอบ" — เกมเรายังใช้การเกิดใหม่รายคน

### กติกาตอนออกแบบ

- 3 เฟสในแมพเดียวกันห้ามใช้วิธีบุกซ้ำกัน สไตล์ประจำแมพต้องอยู่ในอย่างน้อย 1 เฟส และเห็นได้จากหน้าตาแมพ
- ทุกสายต้องมีอย่างน้อย 1 เฟสในรอบแมพทั้งหมดที่ตัวเองเด่น และไม่มีสายไหนเด่นทุกเฟส
- เกิดใหม่ได้เรื่อย ๆ → ทุกสไตล์ต้องมีทางให้คนที่เพิ่งเกิดกลับเข้าไฟต์ได้มากกว่า 1 ทาง (แม้แต่ "ทุบเข้า" ก็ต้องมีทางเปิดอยู่แล้ว 2 ทาง) และเวลาเดินจากจุดเกิดถึงแกนคือ "ราคาของการตาย" เป้า 10–15 วิ ฝ่ายรับเดินสั้นกว่าฝ่ายบุก ~1.5–2 เท่า

## 3. โครงผังหนึ่งช่วงบุก — แบบ "หลายทาง" (ร่าง v1)

> **อัปเดต:** เดิมเสนอให้ใช้โครงนี้ซ้ำทุกช่วง ผู้ใช้แก้ว่าแต่ละแมพ/เฟสต้องบุกต่างกัน (ดูข้อ 2b) โครงด้านล่างจึงเป็นแค่แบบ "หลายทาง" หนึ่งในห้าแบบ

```
                    [ จุดเกิดฝ่ายรับ ]
                           |
          ┌────────────────┼────────────────┐
          |          ╔═════════════╗         |
   ห้องข้างซ้าย ──── ║   โซนแกน    ║ ──── ระเบียง/ที่สูงขวา
   (ทางอ้อม)         ║  รัศมี 16.5 ม. ║      (ทางสูง)
          |          ╚═════════════╝         |
          |                |                |
          |      ── ทางเชื่อมระหว่างเลน ──      |
          |                |                |
      เลนซ้าย          เลนกลาง           เลนขวา
   แคบ 5–8 ม.       ประตูหลัก 12–16 ม.   ทางขึ้นที่สูง
   มุมหักเยอะ         แนวยาว ~40–50 ม.    กำแพงเดิน/หอ
          |                |                |
          └────────── ลานรวมพลฝ่ายบุก ──────────┘
                           |
                    [ จุดเกิดฝ่ายบุก ]
```

- **เลนกลาง (ทางหลัก):** สั้นและตรงที่สุด แต่เปิดโล่ง มีประตูหลักเป็นคอขวด ฝ่ายรับกันง่าย เป็นที่ของสายคุมพื้นที่ (ไฟ ดิน น้ำแข็ง)
- **เลนซ้าย (ทางอ้อม):** ยาวกว่า แคบ มีมุมหักและห้องเล็ก เข้าโซนแกนจากด้านข้าง เป็นที่ของสายประชิดและมือสังหาร (น้ำแข็งประชิด ความมืด สายฟ้า)
- **เลนขวา (ทางสูง):** ขึ้นกำแพงหรือหอ ได้มุมยิงลงโซนแกน แต่ใช้เวลาขึ้นและไม่มีที่หลบมาก เป็นที่ของสายไกลและตัวบิน (ลม แสง ธรรมชาติวางป้อม สายฟ้าธนู)
- **ทางเชื่อมระหว่างเลน:** อยู่ก่อนถึงแกน ให้เปลี่ยนเลน เข้าไปช่วยเพื่อน หรือถอนกลับ โดยไม่ต้องย้อนไปถึงจุดแยกแรก (ตรงกับข้อเสนอเดิมใน `castle-one-area-concept.html`)
- **จุดฮีล:** วางบนเลนซ้ายและเลนขวาฝั่งละ 1 จุด ส่วนเลนกลางไม่มี ทางหลักจะได้เสี่ยงกว่า
- **ช่วงถอยร่น 20 วิ:** ทางจากโซนแกนเก่าไปเขตใหม่ของฝ่ายรับต้องมีอย่างน้อย 2 ทาง ฝ่ายรับจะได้ไม่ถูกดักทางเดียว

## 4. ตัวอย่างธีม 3 ช่วงบุก (ข้อเสนอ ยังไม่เลือก)

แต่ละช่วงมี "วัสดุเด่น" ต่างกัน สายที่ได้เปรียบจึงเปลี่ยนไปตามช่วง ไม่มีสายไหนได้เปรียบตลอดทั้งแมตช์

### ช่วง 1 — หมู่บ้านนอกกำแพงและประตูเมือง (แกน A)
- **บรรยากาศ:** บ้านไม้ ตลาดนอกกำแพง โรงสีริมน้ำ ทุ่งหญ้าขอบหมู่บ้าน เปิดโล่ง แสงกลางวัน
- **เลนซ้าย:** ซอยหมู่บ้านและโรงสีริมลำธาร
- **เลนกลาง:** ถนนใหญ่ถึงประตูเมือง
- **เลนขวา:** เนินหินขึ้นกำแพงนอก
- **โซนแกน:** ลานหลังประตูเมือง
- **วัสดุเด่น:** ไม้ (เผาได้ พังได้), หญ้าและพุ่มไม้, ลำธาร
- **สายที่ได้เปรียบ:** ไฟ (ของไม้เผาได้เยอะ), ธรรมชาติ (มีพืชให้ใช้), น้ำ (ลำธาร)
- **ฝ่ายรับเตรียมตัว 20 วิ:** ปิดประตูด้วยกำแพงไม้ (ธรรมชาติ) หรือกำแพงหิน (ดิน) วางป้อมบนกำแพง

### ช่วง 2 — ลานปราสาท / ตลาดใน (แกน B)
- **บรรยากาศ:** ลานกว้างหลายชั้น ตลาดในกำแพง สวนน้ำพุ โรงตีเหล็ก กำแพงเดินรอบลาน ใช้ลานสำเร็จรูปที่มีอยู่แล้วใน Map Builder ได้
- **เลนซ้าย:** โรงตีเหล็กและคอกม้า (ห้องเล็ก มุมหักเยอะ)
- **เลนกลาง:** ตลาด (ของบังเป็นแผงค้า)
- **เลนขวา:** กำแพงเดินและหอมุม
- **โซนแกน:** สวนน้ำพุกลางลาน
- **วัสดุเด่น:** หิน (กำแพงให้ผลักชน), น้ำพุและรางน้ำ, ของโลหะ (ทั่ง โซ่ ประตูเหล็กดัด), อากาศเปิดสูง
- **สายที่ได้เปรียบ:** ดิน (กำแพงหินรอบลาน), ลม (ลานเปิดให้บิน ผลักชนกำแพง), สายฟ้า (ของโลหะ — ต้องรอระบบสภาพธาตุ)
- **จุดน่าสนใจ:** น้ำพุทำพื้นเปียก เป็นจุดต่อยอดให้น้ำแข็ง (แช่แข็งเป็นพื้นลื่น) หรือสายฟ้า (ช็อต) ตามแผน `element-surfaces.md`

### ช่วง 3 — ปราการใน / โถงใหญ่ (แกน C สุดท้าย)
- **บรรยากาศ:** ภายในอาคาร โถงสูงมีกระจกสีกับลำแสง (มีโถงใหญ่ในเกมแล้ว) ห้องสมุด โบสถ์ หอระฆัง
- **เลนซ้าย:** ห้องสมุดและทางเดินมืด (แคบ เพดาน 6–8 ม.)
- **เลนกลาง:** ประตูใหญ่เข้าโถง
- **เลนขวา:** หอระฆังและระเบียงชั้นสองของโถง
- **โซนแกน:** ท้องพระโรงท้ายโถง
- **วัสดุเด่น:** ห้องปิดเพดานสูง, โคมระย้าและโซ่โลหะ, มุมมืดกับซอกเสา, ระเบียงชั้นสอง
- **สายที่ได้เปรียบ:** ความมืด (มุมมืด ห้องข้างติดกัน), แสง (ไฟต์ระยะกลางในห้อง เพื่อนอยู่ใกล้กัน), น้ำแข็ง (คลุกวงในทางแคบ)
- **ข้อควรระวัง:** ช่วงสุดท้ายในอาคารทำให้สายบินเสียเปรียบ จึงต้องมีโถงหลักเพดานสูง 12 ม. ขึ้นไปให้ลมยังเล่นได้

| ✨ แสง | ไฟต์ระยะกลางที่เพื่อนอยู่ใกล้กัน (ลิงก์หลุดถ้าห่างเกิน 32.5 ม.), จุดยืนหลังแนวหน้าเล็กน้อย, กระจกสีกับแสงแดดในโถง (ไอเดีย ยังไม่ได้ออกแบบ) | เลนที่แยกห่างกันมาก เพื่อนกระจายตัว |

## 6. ชื่อเรียกจุด (callout) แบบ VALORANT

ทุกจุดสำคัญต้องมีชื่อสั้น ๆ ภาษาไทย ไว้คุยในทีมหรือในไมค์ ตัวอย่างช่วง 1:

`ลานรวมพล` · `ถนนใหญ่` · `ประตูเมือง` · `โรงสี` · `ซอยตลาด` · `เนินหิน` · `กำแพงนอก` · `หอซ้าย` · `ลานหลังประตู` (โซนแกน A) · `จุดฮีลโรงสี` · `จุดฮีลเนิน`

- ชื่อควรมาจากของที่เห็นชัดในฉาก (หอ โรงสี น้ำพุ) ผู้เล่นจะได้จำได้ทันที
- แต่ละช่วงต้องมีจุดสังเกตใหญ่อย่างน้อย 1 อย่างที่มองเห็นจากทุกเลน (หอระฆัง ต้นไม้ใหญ่ น้ำพุ) ไว้ใช้บอกทิศ
- ถ้าจะทำต่อ อาจแสดงชื่อจุดบนมินิแมพหรือ HUD ได้ (ยังไม่ได้ออกแบบ)

## 7. หน้าตาและความอ่านง่าย

- **Overwatch:** ทุกช่วงมีธีมและโทนสีของตัวเอง (หมู่บ้านอบอุ่น → ลานหินเทาฟ้า → โถงในแสงกระจกสี) และสีฝั่งชัดเจน (ฟ้าบุก แดงรับ) ที่จุดเกิดและประตู
- **VALORANT:** ในเลนต่อสู้ ของบังใช้ทรงเรียบชิ้นใหญ่ ความสูงชัดเจน 3 ระดับ (ต่ำ ~1 ม. ยืนยิงข้ามได้ / กลาง ~2 ม. บังตัว / สูง ผนัง) ของประดับเล็ก ๆ ไว้ขอบนอกเลน เอฟเฟกต์สกิลจะได้อ่านออก
- **ของพังได้:** วางให้ "พังแล้วเปลี่ยนเกม" เช่น กำแพงไม้ที่พังแล้วเปิดทางลัด หรือหลังคาที่พังแล้วเปิดมุมยิงจากที่สูง ไม่ใช่พังได้ทุกอย่าง (ตรงกับข้อตกลงเดิม: กำแพงพังได้เฉพาะบางจุด พื้นไม่พัง)
- **ขอบแผนที่:** ใช้ฉากหลังแบบเนินวัดบน Cliff Side Castle (มีแล้ว) ให้ดูใหญ่โดยไม่ต้องเดินเข้าไปได้

## 8. วิธีใช้กับแผนที่ Cliff Side Castle ที่มีอยู่

- Cliff Side Castle (`fcs-file`) ใหญ่ประมาณ 630 × 225 ม. มีลานสำเร็จรูป บ้านหินพังได้ และโถงใหญ่อยู่แล้ว
- แนวทางที่เสนอ: **ไม่ต้องสร้างใหม่ทั้งหมด** ใช้ checklist ข้อ 2–5 ตรวจแผนที่เดิมทีละช่วง ว่าแต่ละช่วงมี 3 เลน ทางเชื่อม ที่สูง จุดฮีล และของให้ทุกสายแล้วหรือยัง แล้วค่อยปรับใน Map Builder
- ถ้าตรวจแล้วโครงห่างจากนี้มาก อาจทำผังหยาบใน Map Editor (`mapedit.html`) ก่อน แล้วค่อยสร้างจริงใน Map Builder

## 9. คำถามที่ต้องตัดสินก่อนทำต่อ

1. ใช้โครง 3 เลนต่อช่วงตามข้อ 3 ไหม หรืออยากได้ 2 เลน + ทางสูง
2. ธีม 3 ช่วง (หมู่บ้าน → ลานปราสาท → โถงใน) ตามข้อ 4 โอเคไหม
3. มีจุดตกขอบหรือหน้าผาที่ผลักศัตรูตกแล้ว **ตายทันที** แบบ Overwatch ไหม หรือแค่ตกชั้นล่างเสียตำแหน่ง (ข้อนี้มีผลกับดินและลมมาก)
4. จะปรับ Cliff Side Castle เดิม หรือทำแผนที่บุกปราสาทใหม่อีกอัน
5. เพดานห้องปิด 12 ม. ขึ้นไปพอไหม หรืออยากให้ตัวบินบินได้ทุกที่
