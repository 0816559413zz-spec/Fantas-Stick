# แผนที่: หมู่บ้านในหุบเขา (`valley`)

แบบกรอกตาม `MAP-DESIGN.md` หัวข้อ 1 ตัวเลขทุกตัวเป็นค่าชั่วคราว ทีมเกมเพลย์ปรับได้
ไฟล์ปั้น: `assets/src/maps/valley.blend` (collection `MAP_valley`) สร้างจากสคริปต์ `assets/src/maps/valley_build.py`
สถานะ: ปั้นใน Blender แล้ว **ยังเล่นในเกมไม่ได้** รอระบบโหลดแผนที่จากไฟล์ (เฟส 1) และสคริปต์ export

```
ชื่อแผนที่ (ไทย):      ⛰️ หมู่บ้านในหุบเขา
id:                    valley
คำอธิบายสั้น:          หมู่บ้านริมลำธารกลางหุบเขา สะพานหินเชื่อมสองฝั่ง เนินสูงทั้งเหนือและใต้
ธีม / อารมณ์:          หมู่บ้านชนบทยามบ่าย อบอุ่น มีลำธารไหลผ่านกลางหุบ
ขนาด:                  130 × 86 หน่วย (ขอบเขตเล่น x −65..65, y −43..43) — ขนาดกลาง เทียบฮอกส์มี้ด
เวลา / ท้องฟ้า:        กลางวัน (sky = day)
โหมดที่ใช้ได้:          Co-op / FFA / ดวล / ทีม / BR
อยู่ในรายการสุ่มไหม:   ใช่
จุดเด่นการเล่น:        สะพานหินกลางแผนที่ (สูง 2) แย่งที่สูงกลางสนาม ลอดใต้สะพานได้ตามลำธาร
                       หน้าผาเหนือ (ตรงกลางแผนที่) ขึ้นได้จากทางลาดฝั่งตะวันตก/ตะวันออกเท่านั้น
                       ทางข้ามน้ำตื้น (หินก้าว) ฝั่งตะวันตก x ≈ −40
ที่สูง / ชั้น:          เนินเหนือสูง 5 (ลาดช้าทางซ้าย/ขวา, หน้าผาชันตรงกลาง x 16..44)
                       เนินใต้สูง 3.5 (ลาดทั้งแนว มีกังหันลม)
                       สะพาน floor_ สูง 2 ทางขึ้นเป็นคันดินลาดสองฝั่ง
                       ลำธารต่ำกว่าพื้น 1.4 (ทางข้ามตื้น 0.5)
ที่กำบัง:               บ้าน 7 หลัง (6 หลังในหมู่บ้าน + 1 หลังบนเนินเหนือ), ต้นไม้บนเนินและขอบ,
                       หินก้อนใหญ่, รั้วไม้เตี้ย (กระโดดข้ามได้), แผงตลาด, บ่อน้ำ
พื้นผิวพิเศษ:          💧 น้ำตื้น env_water_ ตามลำธารทั้งสาย
สภาพอากาศที่สุ่มได้:   ฟ้าใส 50% / ฝน 30% / หมอก 20%
เปลี่ยนอากาศกลางเกม:  ได้ ประมาณทุก 4 นาที
ของพังได้:             ลัง 8, ถัง 6, หีบ 2 (เนินเหนือ + เนินใต้), บ้าน 7
เพลง / เสียงบรรยากาศ:  ใช้ของทุ่งหญ้า (meadow) ไปก่อน ขอเสียงลำธาร/นกเพิ่มทีหลัง
ภาพอ้างอิง:            ผังด้านล่าง
หมายเหตุ:              Co-op มอนสเตอร์โผล่ 4 มุม (enemy_spawn_1–4)
                       ทีมแดงเกิดฝั่งตะวันตก ทีมน้ำเงินฝั่งตะวันออก
```

## คำถามที่ยังเปิดอยู่ (ฝั่งเกมเพลย์/โค้ดตัดสิน)
- ตกลงไปในลำธาร: ตอนนี้แค่เดินในน้ำตื้น (ช้าลงตามเฟส 2) ไม่มีจมน้ำ
- หน้าผาเหนือไม่มีดาเมจตก (ระบบยังไม่มี)
