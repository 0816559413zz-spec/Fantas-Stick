# สายฟ้า (Storm) — สมุดไอเดียระหว่างออกแบบ

> สถานะ: **ใส่ลงเกมแล้ว 2026-10-18 (protocol v23)** — ตัวเลขปรับได้หลังลองเล่น • เอฟเฟกต์พื้นฐานลงเกมแล้ว; ร่างอัลติแบบใหม่ (ถอดผ้าคลุม ร่างเป็นสายฟ้า สายฟ้าจากตา) และความทึบสายฟ้าใส่ลงเกมแล้ว 2026-10-18

## แนวการเล่น
- อ้างอิงความรู้สึกการเล่นแบบ Tracer: ว่องไว เข้าออกไฟต์ และเลือกจังหวะใช้แดช
- ใช้ Lightning stack เป็นทรัพยากรของผู้เล่น ไม่ใช่สถานะสะสมบนศัตรู
- อัลติไม่ใช้ Lightning stack (การชาร์จเกจอัลติยังเป็นระบบแยก); ผู้ใช้มีคอนเซปต์แล้ว อยู่ระหว่างจูน

## ภาษาภาพสายฟ้า — ผู้ใช้ยืนยัน
- เอฟเฟกต์สายฟ้าทั้งคลาสที่ดูขาวจางหรือเส้นบาง ต้องเพิ่มความทึบและความชัด แล้วปรับเป็นสายฟ้าหนา สีเหลืองเด่น มีแกนขาวสว่างและเคลื่อนที่เร็ว; แทรกสีรองที่เข้ากับสายฟ้า/สกิลนั้น ๆ ได้ แต่เหลืองต้องเด่นและแรงกระแทกต้องชัด
- ตอนแปลงร่าง Ultimate ผู้เล่นชี้ขึ้นแล้วถูกสายฟ้าฟาดลงมา; ถอดผ้าคลุมออก และให้ทั้งร่างกลายเป็นภาพเงาที่สร้างจากเอฟเฟกต์สายฟ้าสว่างชัดตามภาพอ้างอิง ไม่ใช่ร่างปกติที่มีแค่ออร่าคลุม
- สายฟ้าสีเหลืองแกนขาวพุ่งออกมาจากดวงตาไปทางด้านข้างโดยตรง แลบซิกแซกและเคลื่อนตลอดเวลาแบบภาพอ้างอิงที่สอง; ต้องทึบและเด่น ไม่จาง
- มีส่วนเอฟเฟกต์สายฟ้าด้านหลังชี้เฉียงขึ้นประมาณ 45 องศา
- กรงเล็บสายฟ้าอ้างอิงทรงคมกางออกคล้าย Aoi ใน ROV (ภาพที่ผู้ใช้แนบ); ไม่ใช้กรงเล็บที่เป็นเพียงเส้นสายฟ้าจากไม้กายสิทธิ์
- มีหางสายฟ้าพริ้วไหวและสั่นตามการเคลื่อนไหวของตัวละคร
- ตอนเดินและ Dash ทิ้งร่องรอยสายฟ้าไว้ตามทาง

## ระบบประจุ — ร่างที่ผู้ใช้เห็นชอบให้ใช้เป็นฐาน
- แดชมี 3 ชาร์จ; เวลาฟื้นชาร์จยังไม่ล็อก (แนวคิดเริ่มต้นคือฟื้นทีละชาร์จประมาณ 3 วินาที)
- แดชทะลุศัตรูเก็บ Lightning stack ได้ 1 ต่อการใช้แดช สูงสุด 3 stack
- มีสกิลระยะไกลหนึ่งท่าที่ไม่เสีย stack ใช้เก็บ stack และให้บัฟเล็กน้อย
- Basic Attack ปกติ **ไม่สร้าง Lightning stack**; แหล่งสร้าง stack ที่วางไว้ตอนนี้มีแค่ Dash ทะลุศัตรูและสกิลฟรีระยะไกล
- สกิลอื่นใช้ stack; ค่าใช้จ่ายรายท่ายังไม่ออกแบบ
- ยังไม่ยืนยันว่า stack หมดอายุหรือไม่

## Basic Attack — แนวคิดที่ตกลงไว้เบื้องต้น
- ภาพ/พรอมป์ต์เอฟเฟกต์: ดีดไม้กายสิทธิ์ ปล่อยสายฟ้าสีเหลืองหนามีแกนขาวพุ่งเร็วไปยังกากบาท; ตอนกระทบแตกเป็นกิ่งสายฟ้าสั้น ๆ. อย่าทำเป็นเส้นบางสีฟ้าหรือลูกพลังกลมลอยช้า
- ยิงซ้ำได้เร็ว เดินและแดชได้ระหว่างยิง; ไม่ใช่ลูกพลังกลมลอยช้า
- ระยะยิง: **300 หน่วย** ในโหมดปกติ (ผู้ใช้ยืนยันให้ลดจาก 350)
- ยังไม่ยืนยันความเสียหายและอัตรายิง; Basic Attack ปกติไม่สร้าง stack

## Basic Attack เสริม — แนวคิดผู้ใช้เลือกแล้ว; ตัวเลข/รายละเอียดบางส่วนยังเปิด
- เมื่อเก็บ Lightning stack แล้ว Basic Attack ถัดไปเรียกสายฟ้าฟาดลงมาจากด้านบนเป็นพื้นที่รูปสามเหลี่ยมด้านหน้า ระยะ 250 หน่วย; ภาพอ้างอิงเป็นท่าสายฟ้าของ Baron ใน ROV (สกิล 1)
- VFX ใช้สายฟ้าหนาเหลืองแกนขาวแบบเดียวกับสกิลฟรีเส้นยาว; ไม่ใช้วงหรือเส้นเหลืองบนพื้นเพื่อบอกระยะ
- ทำดาเมจมากกว่าลูกยิงปกติ และทำให้ศัตรูติด **Shock**: ตัวละครโคลง/เสียจังหวะและใช้ Dash ไม่ได้; เอฟเฟกต์ Basic Attack/การโดนของ BA **ห้ามสั่นกล้อง**
- ผู้ใช้กำหนดว่า Shock มีระยะเวลาสูงสุด **0.3 วินาที** เพราะคลาสแดชและโจมตีได้เร็ว
- ยังต้องกำหนดว่า Basic Attack เสริมใช้ Lightning stack 1 ชั้นหรือเป็นโบนัสฟรี, ความกว้างของสามเหลี่ยม, ดาเมจ และกติกาโดนหลายเป้าหมาย
- ในโค้ดปัจจุบัน Shock เพิ่มดาเมจที่เป้าหมายรับและมีคอมโบกับ Storm spells; เมื่อแทนระบบเดิม ผลเพิ่มดาเมจและคอมโบเดิมต้องถูกถอดหรือออกแบบใหม่ให้เข้ากับ Shock แบบเสียจังหวะ
- เพื่อไม่ให้โจมตีเร็วล็อก Dash ต่อเนื่อง: Shock ไม่ซ้อนและไม่ต่อเวลาในขณะที่ยังติดอยู่

## Dash — แนวทางที่ผู้ใช้ยืนยันเพิ่ม
- พุ่งทะลุศัตรูได้; เมื่อทะลุโดนศัตรู สร้างดาเมจ **10** จากสายฟ้าที่พุ่งผ่าน
- ผู้ใช้ต้องการยกเครื่อง VFX ให้ Dash รู้สึกแรงและ impact กว่าเดิม ไม่ใช่แค่เส้นสีเหลืองบาง ๆ
- **ร่างเอฟเฟกต์ที่เสนอไว้ให้ Claude ทำ:** ก่อนพุ่งมีแฟลช/ประกายอัดพลังสั้น ๆ ที่ตัวหรือเท้า; ตอนพุ่งมีสายฟ้าหนาเหลืองแกนขาวหุ้มแนวตัว พร้อม afterimage สั้น ๆ; ทิ้ง wake แตกแขนงไว้ชั่วครู่แล้วสลายเร็ว
- ถ้าทะลุโดนศัตรู ให้เพิ่มแฟลชกระแทกกับประกาย/กิ่งสายฟ้าระเบิดออกจากจุดโดน แยกให้อ่านออกจาก Dash ที่พลาด; เอฟเฟกต์ต้องสั้นและไม่บังฉากนาน
- HUD ของ Dash แสดงจำนวนชาร์จที่เหลือแบบ Tracer: มีสัญลักษณ์สายฟ้าสีเหลืองแยกตามแต่ละชาร์จ; ชาร์จพร้อมใช้สว่างชัด ชาร์จที่ใช้ไปหรี่ลง และกลับมาสว่างทีละอันเมื่อฟื้น
- HUD Lightning Stack: แสดง 5 ชั้นเป็นไอคอนสายฟ้าแบบเดิม ไม่มีวงกลมรองรับ แต่ขยายให้ใหญ่ขึ้นและใช้ทรงซิกแซ็กคมแบบภาพอ้างอิง ขอบส้มทอง ตัวเหลืองสว่างพร้อมไฮไลต์ขาวคม ๆ และแสงเรือง/ประกายตอนเก็บ stack; ช่องว่างเป็นสายฟ้าสีเทาเข้ม • เมื่อได้ stack ใหม่ ประกายวิ่งตามแนวแถวไปเติมไอคอนช่องถัดไป แล้วมีแสงวาบสั้น ๆ ตอนเติมสำเร็จ
- แยกตำแหน่ง Dash gauge ออกจาก stack: Dash arc ย้ายออกไปทางขวาของเป้าเล็ง ส่วนแถว stack อยู่ต่ำลงมาใต้เป้าเล็ง ไม่ให้สองตัวชิดหรือทับกัน
- รายละเอียดฐานเดิม: มี 3 ชาร์จ, พุ่งทะลุศัตรูเพื่อเก็บ Lightning stack (สูงสุด 1 ต่อการใช้ Dash); ระยะ, เวลาพุ่ง, การฟื้นชาร์จ และการเก็บ stack หาก Dash โดนหลายศัตรูยังไม่ล็อก

## สกิลฟรีระยะไกล — แนวคิดใหม่จากผู้ใช้ (กำลังพิจารณา)
- เรียกสายฟ้าจากด้านบนเป็นแนวยาว เริ่มจากตำแหน่งผู้เล่นแล้วผ่าพุ่งไปจนถึงจุดสุดระยะ; ความเร็วเอฟเฟกต์ราว **0.3 วินาที** ไม่ควรมีช่วงรอช้านาน
- ตอนปล่อยท่า ผู้เล่นชี้ขึ้นแล้วกดมือลงเพื่อเรียกสายฟ้าจากด้านบน; ช่วงชี้ขึ้น/ลงรวมประมาณ **0.5 วินาที** และต้องสั้นกว่าท่าของ Ice
- ความกว้างปานกลาง เล็งโดนง่ายกว่าเส้นแคบ แต่แคบกว่า Ice slash wave
- VFX ที่ผู้ใช้เลือก: สายฟ้าฟาดเป็น **ช่วง ๆ ไล่ต่อกันตามแนว** ด้วยความหนาและแรงปะทะแบบเดียวกับ BA เสริม — เหลืองเด่น แกนขาว พร้อมสีรองที่เข้ากันและอนุภาคกระแทก
- ทั้งสกิลฟรีนี้และ BA เสริม **ไม่มีตัวบอกระยะ/วงเตือนสีเหลืองบนพื้น**
- ถ้าโดนศัตรู ให้ Lightning stack **1**; Basic Attack ปกติไม่สร้าง stack
- ยังไม่ตัดสินว่าจะทำให้ติด Shock ด้วยหรือไม่, ระยะ/ความกว้างของแนว, คูลดาวน์, บัฟความเร็วเล็กน้อยเดิมจะอยู่หรือไม่, และถ้าโดนหลายคนจะให้ stack อย่างไร
- แยกภาพจาก BA เสริม: BA เสริมเป็นพื้นที่สามเหลี่ยมระยะ 250 ที่สายฟ้าฟาดลงจากบน; สกิลฟรีนี้เป็นเส้นยาวพุ่งจากตัวผู้เล่นไปสุดระยะ

## สกิลใช้ Lightning stack — ดูดความเร็ว
- ใช้ Lightning **1 stack**; ดูดความเร็วจากศัตรูรอบตัวที่โดนสกิล
- ทำดาเมจ **15 ต่อศัตรู** และขโมยความเร็ว **20% จากแต่ละศัตรู**; ผู้ใช้ได้บัฟความเร็ว **20% ต่อศัตรูที่โดน**, นาน **3 วินาที**, สูงสุด **60%**
- VFX ที่ผู้ใช้เห็นชอบ: สายฟ้าสีเหลืองหนาแกนขาวพุ่งจากศัตรูที่โดนกลับมาหาผู้ใช้ แล้วไหลวนรอบตัวเพื่อสื่อว่าขโมยความเร็วมา; ศัตรูมีแสง/ประกายวูบลงสั้น ๆ ให้เห็นว่าถูกดูดความเร็ว
- ระยะสกิล, คูลดาวน์, การคำนวณบัฟเมื่อติดศัตรูเกิน 3 คน และผลต่อ Dash ยังต้องกำหนด

## สกิลใช้ Lightning stack — สายฟ้าฟาดสามครั้ง (แนวคิดผู้ใช้)
- ใช้ Lightning **2 stacks**
- ต้องเข้าโหมดเลือกจุดวางแบบ Fire Circle แล้วคลิกยืนยันจุดก่อนเริ่ม; ห้ามกดแล้วสายฟ้าลงทันที
- ใช้จุดที่เลือกนั้นฟาด **3 ครั้ง**, แต่ละครั้งทำดาเมจ **30**; ปัจจุบันเว้นจังหวะ **0.5 วินาที** ระหว่างครั้ง
- ก่อนแต่ละครั้งมีวงเตือนที่เห็นชัด เป็นวงเวท/รูนมีลวดลาย ไม่ใช่วงเหลืองเรียบ ๆ; ศัตรูควรอ่านพื้นที่แล้วมีโอกาส Dash/เคลื่อนออก
- ตอนสายฟ้าฟาด ใช้สายฟ้าหนาเหลืองแกนขาวพร้อมสีรองที่เข้ากัน; มีอนุภาคและประกายพุ่ง/กระจายจากจุดปะทะ
- ค่าฐานปัจจุบัน: ระยะเล็ง **600**, วงรัศมี **70**, ดาเมจ **30 ต่อครั้ง**, cooldown **12 วินาที**
- เวลาเตือนเฉพาะของวง, รูปลักษณ์ตัวอย่าง placement preview และจำนวนอนุภาคยังปรับได้
- ถ้าโดนเป้าหมายครบทั้งสามครั้งจะรวมเป็น **90 ดาเมจ**; ต้องทำวงเตือนและจังหวะลงให้ชัดเพื่อให้หลบได้

## ไอเดียเสนอสำหรับสกิลใช้ 2 stack เพิ่มเติม (ยังไม่เลือก)
- **Counterspell Mirror**: ตั้งการ์ดสะท้อนด้านหน้าเป็นช่วงสั้นมาก; ถ้ารับกระสุนเวทได้ จะสะท้อนกลับไปตามแนวเดิมด้วยพลังลดลง; ถ้าศัตรูล่อให้กดก่อนหรือโจมตีประชิด จะเสีย stack โดยไม่ได้ผล
- เป้าหมายคือเพิ่มสกิลสวนเวท/อ่านจังหวะ ไม่เพิ่ม Dash, ไม่เพิ่มท่ายิงพื้นที่แบบเดิม; ยังไม่เลือกและไม่ล็อก

## สกิลใช้ Lightning stack — Railgun (แนวคิดผู้ใช้, 2 stacks)
- ใช้ Lightning **2 stacks**; ร่ายวงเวทเป็นเวลา **0.6 วินาที** แล้วปล่อยลำสายฟ้าทรงพลังเป็นเส้นยาว
- มีอนุภาคสายฟ้าจำนวนมากวิ่งไปตามแนวลำแสง; จุดประสงค์คือใช้โจมตี/ตอดศัตรูระยะไกลหรือปิดงาน
- ระหว่างใช้ ผู้เล่นขยับไม่ได้และกล้องล็อกทิศไว้
- เส้นเตือนสีเหลืองแกนขาวลอยอยู่ในอากาศตามแนวที่จะยิง ไม่ใช่วงหรือเส้นบนพื้น; ให้เห็นเส้น/หางนำทางก่อน แล้วเอฟเฟกต์ลำ Railgun จึงพุ่งตามแนวเดิม
- ตอนยิงให้ลำแสงหนาและทรงพลัง มีสายฟ้าแตกแขนง/พันรอบลำแสง อนุภาคและสีรองที่เข้ากับเอฟเฟกต์ Lightning; ตอนกระทบให้มีแรงปะทะเด่น
- ดาเมจ, ระยะ/ความกว้าง, การทะลุหลายเป้าหมาย และตำแหน่งวงเวทตอนร่ายยังต้องกำหนด

## สกิลใช้ Lightning stack — ลูกสายฟ้าดึงศัตรู (แนวคิดผู้ใช้, 3 stacks)
- ใช้ Lightning **3 stacks**; ผู้เล่นพุ่งขึ้นไปสูงและบินปรับระดับขึ้น/ลงได้เล็กน้อย คล้าย Dragonfall
- ตอนลอยขึ้น ให้สายฟ้าหนา ๆ พัน/แลบไปรอบตัวและพาดผ่านร่าง พร้อมอนุภาคจำนวนมาก ไม่ใช่แค่ออร่าเรียบ ๆ
- ผู้เล่นชูไม้กายสิทธิ์ขึ้นและรวมลูกสายฟ้าขนาดใหญ่; ลูกบอลต้องมีสายฟ้าพันและแตกกิ่งรอบผิวมากขึ้น และสั่นกระตุกแรงขณะชาร์จ แต่ยังอ่านรูปทรงลูกบอลออก
- จากนั้นเล็งจุดยิงได้; ตอนคลิกยิง ผู้เล่นชี้ไม้ลงอย่างรวดเร็วและยิงลูกสายฟ้าเร็วไปยังจุดเล็ง
- เมื่อลูกกระทบพื้น จะค้างเป็นครึ่งวงกลม/โดมครึ่งลูก แล้วดูดศัตรูเข้าหาศูนย์กลางเป็นเวลา **2 วินาที**
- หลังลงพื้น ลูกสายฟ้าค้างอยู่ตรงกลางโดมตลอดช่วงดูด 2 วินาที; ให้เห็นชัดว่าเป็นศูนย์กลางของแรงดูด ไม่หายไปหลังสร้างโดม
- ภาพแรงดูดใช้ **ทั้งสองอย่างพร้อมกัน**: สายฟ้า/อนุภาคหมุนวนเข้าหาศูนย์กลาง และพื้น/ผิวพลังงานดูยุบตัวเข้าหากลางวง
- ศัตรูต้องใช้ Dash เพื่อหนีแรงดูด/ออกจากพื้นที่ได้
- ระหว่างดูด ศัตรูในพื้นที่รับดาเมจ **5 ทุก 0.5 วินาที** (ตั้งใจรวม **20** ตลอด 2 วินาที); เมื่อจบเกิดระเบิดสายฟ้าทำ **50** และใช้ Shock
- ดาเมจรวมเป้าหมายที่อยู่ครบตลอดพื้นที่ = **70**; เมื่อระเบิด อนุภาคและสายฟ้ากระจายออกจากศูนย์กลาง. ผู้เล่นร่วงกลับลงทันทีหลังยิง พร้อมเส้นสายฟ้า/เอฟเฟกต์แนวดิ่งตอนขึ้นและลง
- ยังไม่กำหนดรัศมีโดม, ระยะ/ความสูงบิน, เวลาช่วงชูไม้รวมลูก, ระยะกระสุน, แรงดูด, Shock นานเท่าไร, และผู้เล่นถูกขัดจังหวะได้หรือไม่ระหว่างบิน/ชาร์จ

## Ultimate — ร่างเทพสายฟ้า (คอนเซปต์ผู้ใช้, ยังต้องจูนบาลานซ์)
- แปลงร่างเป็นเทพสายฟ้า **10 วินาที**; เริ่มด้วยชี้ขึ้นและถูกสายฟ้าฟาดลงมา ผ้าคลุมหายไปและร่างถูกแทนด้วยเอฟเฟกต์สายฟ้าสว่างชัด; สายฟ้าพุ่งจากดวงตาไปทางข้างและแลบตลอดเวลา, มีสายฟ้าด้านหลังชี้ขึ้นเฉียง 45 องศา, หางสายฟ้าพริ้วสั่นตามตัว และมีรอยสายฟ้าตามทางเดิน/Dash
- ได้พลังชีวิตเสริม **75**; Dash cooldown เหลือ **1 วินาที** และ Dash ทำดาเมจ **15** (ลดจาก 20)
- ใช้ Shield ไม่ได้ระหว่างอัลติ
- BA เปลี่ยนเป็นคอมโบกรงเล็บสายฟ้าด้านหน้า 3 จังหวะ: **15/15/25** ดาเมจ; จังหวะที่ 3 ทำ Shock; ระยะโจมตี 200 และทุกครั้งมีเอฟเฟกต์กรงเล็บสายฟ้าพุ่งไปข้างหน้าเพื่อสื่อระยะ; ระหว่างอัลติ BA ใช้ภาพกรงเล็บเท่านั้น ไม่ใช้ลำแสงปกติ
- เมื่อ Dash โดนศัตรูระหว่างอัลติ ให้กระตุ้นการโจมตี BA เสริมด้วย; เวอร์ชันเสริมของกรงเล็บมีระยะและความกว้างมากกว่า BA ปกติ และยังแสดงเป็นกรงเล็บเท่านั้น
- VFX เพิ่มเติมที่ผู้ใช้อนุมัติ: ทั้งคอมโบกรงเล็บปกติและการโจมตีเสริมหลัง Dash ต้องมีรอยฟันสายฟ้าหนา สีเหลืองสว่างแกนขาว และ opacity ชัดขึ้น • ท่าเสริมหลัง Dash อ่านเป็นรอยกรงเล็บ 3 เส้นขนานในการโจมตีภาพเดียว • เป็นการปรับภาพเท่านั้น ห้ามเพิ่มจำนวน hit หรือดาเมจ; ใช้ดาเมจเดิม
- ยังต้องระบุว่าการโจมตีเสริมเกิดทันทีหรือรออินพุต BA, ใช้ Lightning stack เพิ่มหรือไม่, และเพิ่มระยะ/ความกว้างเท่าไร
- Speed Siphon มี Shock รอบตัวและระยะไกลขึ้น
- Lightning Orbs เหลือ **2 ลูก**; เมื่อ Dash โดนศัตรู ออร์บทั้งคู่โจมตีพร้อมกันทันที ระหว่าง Ultimate แต่ละลูกทำดาเมจพื้นฐาน **15** โดยไม่คูณเพิ่ม (รวมออร์บ 30 + Dash 15 = burst 45 ก่อนนับสกิลอื่น)
- Railgun ระยะไกลขึ้นมาก; มีเส้นเตือนสีเหลืองก่อนดาเมจ: **0.8 วินาที** ในโหมดปกติ และ **0.5 วินาที** ระหว่างอัลติ
- สายฟ้าฟาดสามครั้งเพิ่มสายฟ้าลงเป็นวงซ้าย/ขวาของแต่ละจุดด้วย วงเสริมเล็กกว่าวงหลัก
- ลูกสายฟ้าโดม: ผู้เล่นถือบอลแล้วพุ่ง/ทุบลงแบบ Dragonfall; ตอนกระทบพื้นดูดศัตรูและระเบิดทันที ทำดาเมจ **80 รวมทั้งหมด**
- ยังต้องกำหนดว่า stack cost ของสกิลยังเท่าเดิมระหว่างอัลติไหม, พลังชีวิตเสริมอยู่จนหมดเวลา/ถูกตีหมดหรือไม่, และคูลดาวน์ Dash 1 วินาทีทำให้เก็บชาร์จเพิ่มอย่างไร
- จุดบาลานซ์ที่ยังต้องเช็ก: +75 HP, Dash ทุก 1 s, ความเสียหายคอมโบกรงเล็บ/ออร์บในจังหวะ Dash, และโดม 80 (ให้นับ 80 เป็นดาเมจรวมก่อน); ยังไม่ต้องเนิร์ฟเพิ่มจนกว่าจะลองเล่น เพราะ Railgun มีเส้นเตือน (0.8 s ปกติ / 0.5 s อัลติ), Orbs ไม่คูณดาเมจ และใช้ Shield ไม่ได้ระหว่างอัลติ

## สกิลใช้ Lightning stack — ออร์บสายฟ้าคู่ (แนวคิดผู้ใช้)
- ใช้ Lightning **1 stack** เพื่อเรียกออร์บสายฟ้า **2 ลูก** ลอยอยู่ด้านหลังผู้เล่น ซ้ายและขวา; ขนาดใหญ่กว่า Fire Orbs
- เมื่อ Dash โดนศัตรู ออร์บจะพุ่งลงไปกระแทก **ตำแหน่งที่ Dash โดน**; ไม่ต้องไล่ตามเป้าหลังจากนั้น
- ออร์บที่กระแทกทำดาเมจ **15** และมีรัศมีโดนรอบจุดกระแทกเล็กน้อย
- VFX (ผู้ใช้ยืนยัน): ต้องเห็นเป็นลูกบอลที่ก่อรูปจากสายฟ้า ไม่ใช่ลูกกลมสีเหลืองธรรมดา; มีแกนขาวสว่างและสายฟ้าหนา ๆ สีเหลืองพันรอบ แตกแขนง/สั่นอยู่ตลอดขณะลอยหลังผู้เล่น. เมื่อ Dash โดน ออร์บพุ่งกระแทกจุดโดนพร้อมแสงวาบและประกายสายฟ้ากระจาย
- Dash ที่โดนศัตรูจะยิงออร์บออก **1 ลูกต่อ Dash** เท่านั้น; ถ้า Dash เดียวโดนหลายศัตรูก็ยังยิงออร์บเพียงลูกเดียว
- ยังไม่กำหนดรัศมีระเบิดและอายุออร์บ

## โล่สายฟ้า — แบบที่ผู้ใช้เลือกเป็นแนวทาง
- กดใช้แล้วสายฟ้าฟาดลงมาที่ผู้เล่น เกิดโล่สายฟ้าสีเหลืองล้อมตัวอยู่นานสูงสุด **3 วินาที**; ผู้เล่นยังเคลื่อนที่และใช้ความเร็วได้ตามปกติ
- โล่ดูดซับดาเมจจากการโจมตีระยะไกลและประชิด; รูปทรงเป็นเกราะสายฟ้าแตกแขนงล้อมตัว ไม่ใช่วงกลมหรือฟองโล่ธรรมดา. สีหลักคงเป็นสีเหลืองตลอดตอนรับดาเมจ; ทุกครั้งที่โดนให้มีแสงวาบ จุดกระแทก และสายฟ้า/อนุภาคแตกแขนงจำนวนมากขึ้น โดยไม่เปลี่ยนไปเป็นสีอื่น
- กดปุ่มขวาอีกครั้งเพื่อระเบิดรอบตัวทันที; ถ้าไม่กด จะระเบิดเมื่อครบ 3 วินาที **เฉพาะเมื่อมีดาเมจถูกดูดซับ**. ถ้าไม่มีใครโจมตี ไม่มีระเบิดและไม่ได้ Lightning stack
- VFX ระเบิดที่ผู้ใช้เลือก: เกราะยุบ/หดกลับเข้าหาตัวแวบหนึ่ง แล้วปล่อย **ทั้งคลื่นกระแทกวงกลมและสายฟ้าแตกแขนงรอบตัวพร้อมกัน**; ใช้สีเหลืองแกนขาว สีรองที่เข้ากัน และอนุภาคกระจาย. วงเป็นคลื่นระเบิดชั่วครู่เท่านั้น—ตัวโล่ที่ดูดซับยังคงเป็นเกราะสายฟ้ารูปทรงไม่สม่ำเสมอ ไม่ใช่ฟองกลม
- เมื่อดูดซับดาเมจรวมเกิน **90** โล่ระเบิดทันที แม้ยังไม่ครบเวลา
- ดาเมจระเบิด = ครึ่งหนึ่งของดาเมจที่ดูดซับไว้ สูงสุด **30**; การระเบิดที่โดนศัตรูอย่างน้อยหนึ่งตัวให้ Lightning stack **1** และทำให้เป้าหมายติด Shock แบบสั้น (ใช้ Shock นิยามใหม่ สูงสุด 0.3 วินาที)
- การดูดซับไม่มีเพดานระหว่าง 3 วินาที แต่ดาเมจระเบิดยังถูกจำกัดที่ 30; ถ้ารับเกิน 90 จะระเบิดก่อนเวลา
- ยังไม่ได้กำหนดคูลดาวน์, รัศมีระเบิด, และผู้เล่นกดระเบิดก่อนครบเวลาโดยยังไม่รับดาเมจหรือไม่ (แนวคิดปัจจุบันคือไม่มีดาเมจสะสมก็ไม่มีระเบิด/stack)

## คำถามที่ยังเปิด
- เอฟเฟกต์ Dash จะใช้สี รูปร่างสายฟ้า และอนุภาคแบบใด?
- สกิลฟรีระยะไกลควรยิงโดนแล้วให้ stack ทันที พร้อมบัฟเล็กน้อย โดยไม่ต้องมีตราหรือเงื่อนไขคอมโบซ้อน
- สกิลเส้นยาวให้ Shock ด้วยหรือไม่?
- ระยะ/คูลดาวน์ของสกิลดูดความเร็ว และบัฟความเร็วมีผลระหว่าง Dash หรือไม่?
- รัศมีและจังหวะของสายฟ้าฟาดสามครั้งเป็นอย่างไร?
- คูลดาวน์และรัศมีระเบิดของโล่สายฟ้าเท่าไร?
- การฟื้นชาร์จแดชและ stack จะกำหนดอย่างไร?
- ท่า Basic Attack เสริมกิน stack หรือไม่? ความกว้าง/ดาเมจ และกติกาโดนหลายเป้าหมายเป็นอย่างไร?

- **UI stack:** สายฟ้า 5 อันใต้เป้าเล็ง • ว่าง = สีน้ำตาลเข้ม • เต็ม = เปลี่ยนเป็นสีเหลือง มีประกายสายฟ้าและสั่น
- **Basic Attack แบบ Winston:** กดค้างยิงลำสายฟ้าต่อเนื่อง (ไม่ใช่คลิกทีละนัด) • **3 ดาเมจ ทุก 0.4 วิ** • ระยะ **300** ล็อกโดนทุกคนในกรวยด้านหน้าอัตโนมัติ (ไม่ต้องเล็งแม่น) • VFX เป็นสายฟ้าหนา สีเหลืองมีแกนขาว แตกกิ่งและพุ่ง/แลบเร็ว ไม่ใช่เส้นบางสีฟ้า • **ไม่สั่นกล้อง**
- **Basic Attack เสริม ยังอยู่:** ได้ stack ใหม่ = กดยิงครั้งถัดไปฟาดสายฟ้าสามเหลี่ยมทันที (20 ดาเมจ ยาว 250 ปลายกว้าง 120 + Shock 0.3 วิ) แล้วถ้ากดค้างต่อก็เป็นลำปกติ • VFX เหลืองหนาแกนขาวแบบสกิลฟรีเส้นยาว; ไม่มีตัวบอกระยะสีเหลืองบนพื้น
- **สายฟ้าฟาดสามครั้ง:** เข้าโหมดวางจุดแบบ Fire Circle แล้วคลิกยืนยัน; มีวงเตือนรูนอ่านง่ายก่อนฟาดจุดนั้น **3 ครั้ง ห่างกัน 0.5 วิ** (ระยะเล็ง 600 วงรัศมี 70 ครั้งละ 30 คูลดาวน์ 12 วิ 2 stacks); ฟ้าผ่าหนาเหลืองแกนขาวและมีอนุภาคพุ่งออกจากจุดปะทะ
- ผู้ใช้สั่ง "ok do it" = เริ่มสร้างสายฟ้าลงเกมตามแบบทั้งหมด

## Claude ตีความตอนใส่ลงเกม (2026-10-18)
- ได้ stack ทุกครั้ง (แม้ stack เต็ม 5 แล้ว) ก็ยังเปิดยิงสามเหลี่ยมนัดถัดไป
- ลำสายฟ้า: กรวยกว้าง ±35° ล็อกได้สูงสุดทุกคนในกรวย (ภาพแสดง 4 เป้า)
- Dash ไม่อมตะ • ระหว่าง Dash ทะลุคนเดิมโดนครั้งเดียว
- โล่สายฟ้าดูดซับดาเมจ แต่สถานะ (สตัน/สลอว์) ยังติด • คูลดาวน์โล่นับหลังโล่จบ • แถบโล่เดิมใช้แสดงคูลดาวน์
- เส้นสายฟ้า: ทิศล็อกตอนกดลง (ครบ 0.5 วิ) • โดนสตันระหว่างชูไม้ = ยกเลิก (คูลดาวน์ยังเดิน)
- ฟ้าผ่าสามครั้งระหว่างอัลติ: วงข้าง ห่าง 110 รัศมี 45 ดาเมจครั้งละ 30 เท่ากัน
- Railgun: เส้นเตือนเป็นแถบบนพื้น • โดนสตันระหว่างร่าย = ยกเลิก (เสีย stack)
- โดมดูดศัตรูตัวใหญ่/บอสไม่ได้ • โดมทุบตอนอัลติ = ดึงเข้าแรงๆ ครั้งเดียว + 80
- อัลติ: ใช้ไปตอนเปิดโล่อยู่ = โล่หายไม่ระเบิด และคูลดาวน์โล่รีเซ็ต

- ผู้ใช้แก้ (2026-10-18): ร่างเทพ **ตัวละครยังเป็นตัวเดิม** (สีเดิม มีผ้าคลุม) ไม่ใช่ตัวสีเหลือง — มีแค่เอฟเฟกต์สายฟ้า (ตา หลัง กรงเล็บ หาง สายฟ้าวิ่งรอบตัว)
- ผู้ใช้สั่ง (2026-10-19): ร่างอัลติเท่ขึ้น — **กรงเล็บเข้ม มีสายฟ้าตลอด** (ปั้นใน Blender: สนับมือ + ใบมีดโค้ง 3 เล่ม สีเข้ม คมเหลือง) • **ตาแบบเดกุ** ชัดขึ้น (แกนตาคม + สายฟ้าลากเป็นหางจากตาออกข้าง/หลัง) • BA ตอนอัลติ = กรงเล็บ 3 เส้นเดิม แต่ **เข้ม + สายฟ้าวิ่งตามรอย** • **ไม่เรืองแสงเกิน** (ลดแสงเรืองสายฟ้าบนตัว/กรงเล็บ) — ใส่ลงเกมแล้ว
- ผู้ใช้ตอบ (2026-10-18): กรงเล็บเสริมตอนอัลติ **รอกดยิง** (Dash โดน = ฟันครั้งถัดไปเป็นกรงเล็บใหญ่) • **ไม่ใช้ stack** • ระยะ **280** กว้างขึ้น **50%** ดาเมจ **25** + Shock — ใส่ลงเกมแล้ว พร้อม BA ระยะ 300, ลูกสายฟ้าค้างกลางโดม 2 วิ, HUD ชาร์จ Dash แบบ Tracer
- ผู้ใช้แก้ (2026-10-18): HUD ชาร์จ Dash **ไม่ใช้รูปสายฟ้า** (ซ้ำกับ stack) → เป็นแถบโค้ง 3 ช่องรอบเป้าด้านขวาแบบ Tracer สีฟ้าขาว
- ผู้ใช้แก้ต่อ (2026-10-18): แถบโค้งชาร์จ Dash ให้เป็น **ธีมสายฟ้า** → แถบเป็นกระแสไฟซิกแซกสีเหลืองมีประกาย (ยังเป็นแถบโค้ง ไม่ใช่ไอคอนสายฟ้า)
- ผู้ใช้แก้ (2026-10-18): แถบ Dash ใหญ่ขึ้น สายฟ้ามากขึ้น และ **นับ/หายจากบนลงล่าง**
