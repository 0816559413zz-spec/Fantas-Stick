# UI/UX ใหม่: เมนูแรก → ท่าโพส → การ์ดโหมด → ห้องรอเริ่ม (ผู้ใช้ 2026-10-22)

> สไตล์ทุกหน้า: **minimalist fancy** — เส้นบาง ไม่หนา ตัวอักษรเซอริฟบางเรือง ธีมห้องมืด น้ำเงินเข้ม-ม่วงอ่อน
> รูปอ้างอิงที่ผู้ใช้ส่ง: (1) หน้า VICTORY เกมเกาหลี — ชื่อใหญ่มุมซ้ายบน มีประกายดาว + เส้นบาง (2) การ์ดเลือกโหมด NCSOFT — การ์ดมีภาพพื้น ไอคอนในกรอบหกเหลี่ยม คำอธิบายด้านล่าง (3) Rome Explorer — การ์ดเรียงโค้งแบบ 3D (ใช้กับหน้าเลือกแผนที่) (4) วงสกิลแบบวงกลม + แถบเลือกด้านบน (ใช้กับหน้าเลือกคาถา)

## คำของผู้ใช้ (ย่อ)
1. **เมนูแรก**: ชื่อเกมมุมซ้ายบนแบบรูป 1 • เมนูอยู่ใต้ชื่อ แบบเมนูก่อนหน้า (เลิกใช้ลานเดินได้) • **ขวา** = โต๊ะ มี **ผ้าสีม่วงขอบเส้นทอง + มุมทอง** วางบนโต๊ะแบบ "ไม่ตรงกับรูปทรงโต๊ะ" • **ไม้กายสิทธิ์บนโต๊ะมีประกายแสง** • ของจุกจิกของนักเวท • เมนูเล่นอยู่ซ้าย • ตั้งค่า/แต่งตัวเป็น **ปุ่มเล็กมุมซ้ายล่าง**
2. **กด "เล่น"**: UI จางหาย → ตัวละครหยิบไม้ หันมาหาเรา เดินมายืนตรงหน้า → **โพส 2 แขนกางออก มือหนึ่งถือไม้** idle เล่นกับลูกแก้วเวท ขยับนุ่มมาก **เล่นมุมกล้อง: มือใกล้เรา ตัวไกลหน่อย** หายใจตลอด • ห้องมืด ธีมน้ำเงิน-น้ำเงินเข้ม-ม่วงอ่อน
3. **พอโพสเสร็จ UI เลือกโหมดเด้งขึ้น**: จอแบ่งแนวตั้ง 3 ส่วน — บน+กลาง = ตัวละคร, ล่าง = การ์ดโหมดบนพื้นหลังตาราง (grid) ใหญ่ • การ์ดมีภาพพื้นของโหมด • กลางการ์ด = ไอคอนในกรอบ **หกเหลี่ยม** • คำอธิบายสั้นมากด้านล่าง (พื้นดำเฟดขึ้น) • ออกแบบ hover • ตอนนี้ 4 โหมด: **FFA / Team PVP / Dungeon / Training**
4. **กดการ์ด**: พื้นหลัง (ตัวละครที่โพส) **เฟดดำ** (เฉพาะพื้นหลัง) → การ์ด **หมุนพลิกไปอีกด้านแล้วขยายใหญ่** กลายเป็น UI ตั้งค่าก่อนเริ่มโหมด → โผล่ที่ **ล็อบบี้ใหม่** (สร้างใหม่สำหรับรอเริ่ม)
   - ล่างของ UI = ตั้งค่า + **เปิด/ปิดไมค์** • **ขวาล่าง = เริ่มเล่น** + เลือกด่าน
   - ปุ่มเลือกด่าน = ภาพด่านที่เลือกอยู่ เฟดดำ ชื่อด่านสีขาวซ้ายล่าง • ขวาล่างมีคำว่า **Change map** เล็กๆ จางๆ ไม่หนา • มี hover
   - กด Change map → เฟดดำ โชว์การ์ดทุกด่านแบบรูป 3 • การ์ด **สว่าง 70% บน** ล่างเฟดดำ มีชื่อด่าน + ภูมิประเทศสั้นๆ • เลือกได้ • มี hover
   - **เลือกคาถาอยู่ในการ์ด** — กดแล้วขึ้น **ห้าเหลี่ยม 4 อัน** แบบรูป 4 (ให้ Claude ออกแบบ)
   - ทุกอย่าง animation ลื่นที่สุด

## คำตอบของผู้ใช้ (ถามก่อนนอน 2026-10-22)
- ออนไลน์: **ห้องออนไลน์อัตโนมัติ** — กดการ์ดโหมด = เปิดห้องทันที รหัสห้อง + คัดลอกลิงก์เชิญอยู่มุมการ์ด • เมนูซ้ายมี "เข้าห้องเพื่อน" (ช่องใส่รหัส) ใต้ปุ่มเล่น • ไม่มีเน็ต = เล่นคนเดียวได้
- ล็อบบี้: **ตัวละครทุกคนยืนโชว์ด้านขวา** การ์ดใหญ่อยู่ซ้าย — "cooler pose too, different pose different place" (แต่ละคนท่าต่างกัน ตำแหน่งต่างกัน)
- เลือกคาถา: **วงคาถา + ห้าเหลี่ยม 4 ช่อง** — บนสุด = แถบเลือกสาย • กลาง = วงกลม คาถาของสายเรียงรอบวง ชี้ตัวไหนชื่อ+คำอธิบายขึ้นกลางวง • ล่าง = ห้าเหลี่ยม 4 ช่อง Q E R F คลิกคาถา = ใส่ช่องที่เลือกอยู่
- ภาพการ์ดโหมด/แผนที่: **ถ่ายจากแผนที่ในเกม** (ปรับโทนมืดให้เข้าธีม) เปลี่ยนเป็นภาพของผู้ใช้ทีหลังได้

## สิ่งที่ Claude เลือกเอง (บอกผู้ใช้ด้วย)
- ปุ่มเล็กซ้ายล่าง: ตั้งค่า • แต่งตัวละคร • คู่มือ • เพลงของฉัน • เลเวล/สถิติ
- ฉากเมนู: ห้องทำงานนักเวทมืดๆ หน้าต่างโค้งแสงจันทร์ฟ้า • โต๊ะกลม + ผ้าม่วงสี่เหลี่ยมวางเฉียง (มุมห้อยลงขอบโต๊ะ) ขอบทองสองเส้น + ลายมุมทอง • ของบนโต๊ะ: ลูกแก้วพยากรณ์, หนังสือเปิดมีรูนเรือง, กองหนังสือ, ขวดยา 3 ขวด, เทียน, นาฬิกาทราย, วงแหวนดาราศาสตร์หมุนช้าๆ, ไพ่ทาโรต์, ขนนก+ขวดหมึก • ตัวละครยืนหลังโต๊ะ ก้มมองโต๊ะ
- ท่าโพส: แขนซ้ายยื่นมาทางกล้อง หงายมือ ลูกแก้วเวทลอยหมุนเหนือฝ่ามือ (ใกล้กล้อง = ใหญ่) • แขนขวากางออกข้างถือไม้ ปลายไม้เรือง • หัวมองกล้อง
- ในห้อง โฮสต์เปลี่ยนโหมดได้จากหัวการ์ด (ไอคอนหกเหลี่ยมเล็ก 4 อัน) ไม่ต้องออกห้อง
- โหมดที่ยังไม่อยู่ในการ์ด (ดวล 1v1, ควิดดิช, แข่งไม้กวาด, แบทเทิลรอยัล, หาโวลเดอมอร์) ซ่อนไว้ — โค้ดยังอยู่ครบ
- ออกจากห้อง = กลับมาหน้าการ์ดโหมด (ไม่ต้องดูฉากเปิดใหม่)

## แก้ตามผู้ใช้ 2026-10-23
- ปุ่ม **เริ่มเกม + เลือกแผนที่ ย้ายไปมุมขวาล่างของจอ** (ไม่อยู่ในการ์ด) — การ์ดเหลือ ไมค์/คุยทีม/ตั้งค่า ด้านล่าง

## รอบ 2 — ผู้ใช้ 2026-10-23 (สิ่งที่สั่ง + คำตอบ)
- ลบ "ดวลเวทมนตร์ / A WIZARD DUEL" → คำโปรยภาษาอังกฤษ (ผู้ใช้: "english, something else") ⚠ Claude เขียน: "Four Elements · One Arena" + "Pick your element, build your spellbook, and duel your friends online."
- ปุ่ม เล่น/เข้าห้องเพื่อน ธรรมดาไป แต่ไม่เอากรอบ → ไอคอนหกเหลี่ยมเส้นบาง + เลขโรมัน I/II + คำอธิบายจาง + แสงฟุ้งจากซ้ายตอนชี้ + ลูกศร + ประกายวิ่งผ่านคำ "เล่น"
- ฉากแรก = โต๊ะสี่เหลี่ยมใหญ่เต็มจอ ไม่มีตัวละคร • เฟอร์นิเจอร์ (⚠ Claude เลือก: เก้าอี้พนักสูง ชั้นหนังสือ ต้นไม้ในกระถาง หม้อปรุงยา กล้องดูดาว ลูกโลก พรม หีบ ชั้นขวดยา แผนที่ดาว) • แสงมุมเดียวจากหน้าต่างด้านขวา
- กดเล่น: ไม่เดินเข้าเฟรม — มือเอื้อมหยิบไม้ ยกขึ้น หมุนตัว ผ้าคลุมสะบัดบังจอ แล้วออกมาเป็นท่าโพส • กล้องเริ่มต่ำ ~2/5 ของตัว แพนขึ้น มือที่ใกล้กล้องดูใหญ่ • ปลายไม้มีเอฟเฟกต์เบาๆ
- หัวหมุนตลอด = บั๊ก (คอสะสมการหมุน) แก้แล้ว + หันหัวช้าลง
- การ์ดโหมด **เลื่อนขึ้นสูง** (คำตอบ) • เพิ่มปุ่มรอบจอ (⚠ Claude เลือก: ชื่อ/เลเวล ตั้งค่า เพลง ขวาบน • จัดคาถา แต่งตัว คู่มือ เลเวล ซ้ายล่าง • เข้าห้องด้วยรหัส ขวาล่าง)
- **กดกลับ = แอนิเมชันย้อน ทุกปุ่มกลับ** (คำตอบ): หน้าโหมด→เมนู (เล่นลำดับหยิบไม้ย้อน), ออกจากห้อง (แผงหดกลับเป็นการ์ด), วงคาถา, เลือกแผนที่
- วงคาถา: แยกให้ชัดว่าอะไรคือชุดที่ใส่ (LOADOUT) อะไรคือที่เลือก
- ตั้งค่า: แบบรูปอ้างอิง (วงโค้งซ้ายมีปุ่มกลมไอคอน + ขวาเป็นตัวเลือกจุด/เส้นใต้) ไม่ใช่หน้าใหม่ — เฟดพื้นหลัง ไม่มีรูปในวง ใส่พื้นไล่สีแทน • **ในเกมจะเป็นอีกแบบทีหลัง แต่ตอนนี้ใช้แบบเดียวกับเมนูไปก่อน** (คำตอบ)
- หน้าแรก (โลโก้ตอนเปิดเว็บ): แบบรูป MOTH — ตัวใหญ่ "FTA" ตรงกลาง มีไอคอนแทรกระหว่างตัวอักษร ข้างล่างตัวเล็ก "FANTAS STICK" • ตอนขึ้นให้ค่อยๆ มาทีละส่วนจากด้านบน • หน้าสร้างตัวละครใช้โทน/ฟอนต์เดียวกับเมนู (Claude ออกแบบเอง)
