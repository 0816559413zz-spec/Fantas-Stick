## ยิงปกติ (BA) — แส้หนาม
- คำผู้ใช้: "ba is using whip thorn u will wield left and right kinda slow but middle range 7 damage whip will only come out when u wield wand and gotta make it smooth too when wielding like actual whip"
- แส้หนามออกจากไม้กายสิทธิ์ **เฉพาะตอนตวัด** (ไม่ตวัด = ไม่มีแส้)
- ตวัด ซ้าย → ขวา สลับกัน ค่อนข้างช้า
- ระยะกลาง • ดาเมจ 7 ต่อครั้ง
- ภาพ: แส้ต้องลื่นเหมือนแส้จริง (โค้งตามแรงเหวี่ยง ปลายตามหลัง สะบัดที่ปลาย)
- จังหวะภาพที่ผู้ใช้แก้: ตอนเริ่มแส้ขดงอ มือเริ่มเร่งสร้างแรงแล้วฟาดเร็วผ่าน 120° พอพยายามหยุด มือยังเหวี่ยงเลยตามแรงก่อนค่อยเบรก ปลายแส้ตามช้าและสะบัดต่อ/โค้งตอนจบ ไม่ใช่แค่บังคับให้ขดสองปลายของแอนิเมชัน
- เมื่อมือเบรก ปลายต้องยังสะบัดออกไปไกลกว่าโคนตามแรง แล้วค่อยคลายกลับ ไม่หยุดเป็นเส้นตรงพร้อมกัน
- ผู้ใช้ขอปลายโค้งมากขึ้นและให้ศึกษาฟิสิกส์: โค้งคล้าย U เคลื่อนจากโคนไปปลายก่อนคลายสะบัด อ้างอิงงานวิจัย https://www.sciencedirect.com/science/article/pii/S0167278903002215 ตัวอย่างเป็นการวาด motion โดยประมาณ ไม่ใช่การจำลองฟิสิกส์เต็มรูปแบบ
- คำแก้ล่าสุด: **ตอนฟาดจบแส้ต้องยังโค้งเป็นรูป U แล้วจบในทรงนั้น** ไม่ให้ปลายคลายกลับเป็นเส้นตรงก่อนหาย
- **อัปเดตจากผู้ใช้ 2026-11-03:** ระยะโจมตี 280 หน่วย (14 ม.) กวาด 120° ด้านหน้า; ตัวแส้และท่าเหวี่ยงเลยขอบ 120° ได้ตามแรง ไม่หยุดทันทีที่ขอบเขตโจมตี • ตวัดห่างกัน 0.8 วิ (~9 ดาเมจ/วิ) • โดนทุกคนในเขต (คนละครั้งต่อการตวัด) • กดค้าง = ตวัดซ้าย-ขวาสลับไปเรื่อยๆ ต่อกันลื่น

## สี

## พุ่ง (Dash) — เถาวัลย์เกี่ยว (grappling hook)
- คำผู้ใช้: "so dash is maybe like grappling hook but only work with ur own plant teammate and enemies not sure if i should do enemies too? but u have to aim if u wanna hook to teammate there will be like easier to lock cuz there assist aim bigger hitbox i can send image of ref how will it look as hitbox ui for teammate and our plant for enemy u gotta aim directly to and hit only to pull u into when hit enemies or teammate thorn will พันรอบตัว them and last like 3 sec for teammate thorn will heal them up 10/0.5sec if hit enemy it will poison them 7/sec and slow 50% if u hook to plant u get speed boost 50% 3 sec too but not sure if plant will buff or sum"
- เกี่ยวได้เฉพาะ: **พืชของเรา • เพื่อนร่วมทีม • ศัตรู (ผู้ใช้ยังไม่แน่ใจเรื่องศัตรู)**
- ต้องเล็ง • เพื่อน/พืชเรา = มีตัวช่วยเล็ง (hitbox ใหญ่ + UI ล็อกเป้า — ผู้ใช้จะส่งรูป ref ของ UI) • ศัตรู = ต้องเล็งโดนตรงๆ
- โดนแล้ว **ดึงตัวเราไปหาเป้า**
- โดนเพื่อน/ศัตรู: หนามพันรอบตัวเป้า 3 วิ
  - เพื่อน: ฮีล 10 ทุก 0.5 วิ (= 60 ใน 3 วิ)
  - ศัตรู: พิษ 7/วิ + ช้า 50% (3 วิ = 21 ดาเมจ)
- เกี่ยวพืชเรา: เราได้วิ่งเร็วขึ้น 50% 3 วิ (ผู้ใช้ยังคิดว่าพืชจะได้บัฟอะไรไหม)

- **ตัวเลข (ผู้ใช้เลือก):** เกี่ยวศัตรูได้ • คูลดาวน์ 8 วิ เท่ากันทุกเป้า • ระยะ 15 ม. (300) • เกี่ยวพลาด = เสียคูลดาวน์เต็ม
- ⚠ Claude ตั้งเอง (ยังไม่ได้ถาม): เถาวัลย์พุ่งไป ~0.2 วิ, ดึงตัวเรา ~40 ม./วิ
- **แนว VFX ที่ผู้ใช้เลือก:** สะบัดไม้ไปด้านข้างก่อน เถาเริ่มขดที่ปลายไม้ → พุ่งคลายและโค้งอย่างลื่น → พันรอบเป้าแล้วตึงระหว่างดึงตัวผู้เล่น → คลายเมื่อถึงเป้า; ต้นไม้ที่ถูกเกี่ยวเอนรับแรงเล็กน้อยแล้วคืนตัว เถาพันศัตรูพร้อมภาพพิษ ต้นแบบ `tools/nature-preview.js?sk=dash` เป็นการประมาณภาพการเคลื่อนไหว ไม่ใช่ฟิสิกส์จริงหรือการยืนยันเวลาพุ่งที่ยังไม่ได้ตกลง
- **ผู้ใช้แก้ล่าสุด:** เหวี่ยงเถาออกไปทางด้านข้างแล้วอ้อมเข้าหาและพันเป้าโดยตรง จากนั้นมีดีเลย์เล็กน้อยก่อนดึงผู้เล่นเข้าไป ระยะเวลาดีเลย์แน่นอนยังไม่ได้ระบุ
- **ทิศทาง/แรง (แก้ล่าสุด):** เหวี่ยงออกทางขวาให้กว้างและเร็วมาก เถายังโค้งพลิ้วตามแรงระหว่างเหวี่ยง เมื่อโดน/พันเป้าจึงกระชากเป็นเส้นตึงก่อนดึงตัวเรา
- **คำแก้ต่อมา:** เพิ่มความงอที่ปลายระหว่างเหวี่ยง และขณะตัวเราเข้าใกล้เป้าระหว่างดึง ให้เถาหย่อน/โค้งเป็นห่วงตามระยะที่สั้นลง ไม่ตึงเป็นเส้นตรงตลอด (ขนาด/ทรงห่วงยังรอผู้ใช้ดู)
- **คำแก้ล่าสุด:** เริ่มเหวี่ยงตั้งแต่ข้างตัว วงเหวี่ยงกว้างขึ้น ปลายงอตามแรงมากขึ้น; ตอนเกี่ยวติดให้เน้นแรงตึง/กระตุกด้วยการเคลื่อนไหวก่อน เอฟเฟกต์ภาพของ Dash และ BA ค่อยออกแบบท้ายสุด
- **ทบทวนจังหวะตึง:** ผู้ใช้ชอบแนวทางและขอให้ตอนตึงดูดีขึ้นอีก เน้นมือรับแรง เถาสั่นสะท้อนและเป้าขยับรับแรงก่อนตัวเราถูกดึง โดยยังไม่เริ่มออกแบบ VFX

### พืช 1 — ป้อมยิง (ตัวหลัก)

- **ผู้ใช้เลือก:** ต้นกล้าฝักยิงหนาม — หัวเป็นฝักเมล็ดทรงหยดน้ำ ใบเป็นปีก ยิงหนามแหลมสีเขียวจากปลายฝัก

- เลือด 60 HP ศัตรู/บอทตีตายได้
- วาง: คำผู้ใช้ "u will throw like seed or sum if it hit where it can be place it will instantly come up with animation for sure can be place on wall too if wall like flat" = โยนเมล็ด → ตกตรงที่วางได้ = งอกขึ้นทันทีพร้อมแอนิเมชัน • **ติดกำแพงได้ถ้ากำแพงเรียบ** (รากเกาะผนัง ลำต้นตั้งขึ้นและเอนออกเล็กน้อย)
- VFX/motion: พืชงอกขึ้นเอง ไม่มีก้อนดินหรือดินกระเด็นบนกำแพงหรือหญ้า; ถ้าติดกำแพงให้โคนเกาะผนังและต้นตั้งขึ้นเอนออกเล็กน้อย
- **ผู้ใช้แก้:** เมื่อเกาะผนัง ให้ต้นตั้งขึ้น รากยึดผนัง; ขยายหัวฝักเล็กน้อยและเพิ่มรายละเอียดให้ลำต้น
- **ผู้ใช้แก้ต่อ:** ต้นติดกำแพงตั้งขึ้นแต่เอนหัวออกจากผนังเล็กน้อยเพื่อไม่ให้ชน; ออกแบบใบโคนใหม่ให้ดูเป็นธรรมชาติมากขึ้น (รอผู้ใช้รีวิวภาพ)
