# สายลม (Wind) — สมุดออกแบบ

> ผู้ใช้ออกแบบเองทั้งหมด (สัมภาษณ์ทีละข้อ เริ่ม 2026-10-21). Claude แค่จดคำตอบ — ห้ามคิดตัวเลข/สกิลเอง.
> สถานะ: **กำลังออกแบบ** (ยังไม่ทำในเกม)

## ภาพรวมสาย
- **แนวการเล่น:** นักฆ่าระยะใกล้ คล้าย Yasuo — คุมการเคลื่อนที่ของศัตรู / ทำให้ศัตรูขยับยาก แล้วเข้าไปฆ่าในระยะของเรา. **จุดอ่อน: สู้ระยะไกล.**
  - ผู้ใช้: “almost like yasuo but u will mainly like assasin u can control player movement or make em harder to move and use the short range attack assasin them in ur range weakness is surely range battle”
- **อาวุธ:** ไม้กายสิทธิ์ (เหมือนสายอื่น) — ผู้ใช้: “we r magician lol surely wand”
- **สี:** เขียวมิ้นต์ + ขาว (~`#7fe8c8`) **และ** ใบไม้ปลิวไปกับลม (เขียวอ่อน) — ผู้ใช้เลือกทั้งสองแบบ
- **ระบบประจำสาย:** ยังไม่เลือก — Claude เสนอ reference ให้แล้ว 6 แบบ: (1) ลมกด ซ้อนชั้น ช้าลง ครบชั้นติดพายุ (Yasuo Q / Janna) (2) ฆ่าแล้วรีเซ็ต Dash/สกิล (Genji / Jett) (3) เหยื่อตัวเดียวโดนแรงขึ้น (Kha'Zix) (4) ยกลอยแล้วเก็บ (Yasuo R) (5) หายตัวในพายุฝุ่น (Akali) (6) แรงลมสะสมจากการเคลื่อนที่ (Momentum). ผู้ใช้: “gotta find ref in chatgpt first then i'll let u know”

## Basic (คลิกซ้าย)
- ยิงลูกที่เลือกออกไป มีดาเมจ (ติดสถานะไหม = ผู้ใช้ยังไม่แน่ใจ). กด 1 ครั้ง = ยิง; **กดอีกครั้งตอนลูกกำลังพุ่ง = ลูกหยุดกลางทาง**. **กด V = เรียกลูกกลับ**.

## รอบ 2 (ผู้ใช้ตอบเพิ่ม 2026-10-21)
- **ลูกลมมี 1 ลูก** (แบบผลัก/ดึง/ล็อค ตามที่เลือก). ลูกค้างอยู่ที่หยุด; **ถ้าเราห่างเกิน 700 ลูกกลับมาหาเราทันที**. ผู้ใช้: “1 but orb will stay there but if u go too far like 700 range it will call back immedietly”
- **คลิกขวาแตะ = เปลี่ยนแบบลูก**. **บล็อก = ร่างลม** (อมตะ + เดินเร็ว ตีไม่ได้ 5 วิ). หลังใช้ร่างลมแล้ว โล่ที่เหลือเป็นโล่ธรรมดาแบบน้ำแข็งแต่อ่อนกว่า. ผู้ใช้: “just tap there no wind mode? wind mode is block after wind mode u use noob ass shield like ice too but worse” ⚠ ตีความ: กดค้างคลิกขวา = ร่างลม (ถ้าพร้อม) / ถ้าร่างลมติดคูลดาวน์ = โล่ธรรมดาอ่อน ๆ
- **ลูกที่หยุดค้าง ไม่ทำอะไรเอง** — มีสกิลที่สั่งลูกให้ทำงาน (สั่งได้ 3 แบบตามโหมดลูก). ผู้ใช้: “there will has skill that activate it can activate 3 of them depand on what orb mode”
- ร่างลม: **อมตะ + เดินเร็ว ตีไม่ได้**

## ตัวเลขรอบ 3 (ผู้ใช้เลือก 2026-10-21)
- **ลูกลม:** ดาเมจ **10 ตอนพุ่งไป / 10 ตอนเรียกกลับ (V)** ⚠ ตีความจาก “10/10 then” (ตอบข้อ “15 ไป + 15 กลับ”). ไม่ติดสถานะ.
- **ร่างลม (บล็อก):** คูลดาวน์ **12 วิ**; ระหว่างรอ = โล่ธรรมดา **75 HP**.
- **ออกจากร่างลม:** ปล่อยพลังรัศมี **200** — ผลัก = ระเบิดดันศัตรูรอบตัวออก / ดึง = ดูดเข้าหาเรา / ล็อค = ขังคนในวง.
- **Dash:** ดีดตัวเรา **350** ไปทางตรงข้าม, ผลักศัตรูด้านหน้าในระยะ **200**, คูลดาวน์ **5 วิ**, ไม่มีดาเมจ.

## รอบ 4 (ผู้ใช้เลือก 2026-10-21)
- **ลูกลมพุ่งได้ไกลสุด 400 แล้วหยุดค้างเอง** (ถ้าไม่กดหยุดก่อน).
- **ตอนลูกอยู่ข้างนอก คลิกซ้าย = ยิงลมเล็กอ่อน ๆ** (ไม่มีลูกในมือ).
- **ออกจากร่างลมแบบล็อค:** ขังคนในวง **3 วิ** แต่ **Dash ออกได้**. ผู้ใช้: “can dsh out but ขัง 3วิ”
- **โล่ธรรมดา 75 HP:** กันด้านหน้า, **ฟื้นเต็มทุกครั้งที่ร่างลมพร้อม**.

## รอบ 5 (ผู้ใช้เลือก 2026-10-21)
- **ลมเล็กอ่อน ๆ** (ตอนลูกอยู่ข้างนอก): **5 ดาเมจ ทุก 0.4 วิ ระยะ 400**.
- **ร่างลม:** เดินเร็วขึ้น **40%**; ตอนออกมา คนในวง 200 โดน **15 ดาเมจ** + ผลตามแบบลูก.
- **ออกจากร่างลม:** ผลัก = กระเด็น **~300** / ดึง = **ดูดมาติดตัวเรา** / ล็อค = ขัง 3 วิ (Dash ออกได้).
- **คลิกขวาแตะเปลี่ยนแบบได้ตลอด** — ลูกที่ค้างอยู่ข้างนอกเปลี่ยนแบบตามทันที.

## สกิล (เริ่ม 2026-10-21)
- **สกิล 1 — สั่งลูกระเบิด:** ระเบิดที่ตำแหน่งลูก ผลตามแบบลูก (ผลัก = ดันออกจากลูก / ดึง = ดูดเข้าหาลูก / ล็อค = ขังรอบลูก). ตัวเลขยังไม่ถาม.
- **สกิล 2–5:** ผู้ใช้ยังไม่มีไอเดีย ให้ Claude เสนอแบบ "คอมโบกับลูก" — ผู้ใช้: “no yet but if u want to give idea try think and maake it about combo with orb”
- **ไอเดียที่ Claude เสนอ (รอผู้ใช้เลือก 4 อัน — ยังไม่ได้เลือก):** (1) สลับที่กับลูก — วาร์ปไปที่ลูก ลูกกลับมือ (2) เส้นลมคม — เส้นระหว่างเรากับลูกบาดคน / แบบดึงลากคนเข้าลูก (3) ฟันลมผ่านลูก — ผ่านลูกแล้วแรงขึ้น + ผลตามแบบ (4) ลูกโคจร — หมุนรอบตัวตีคนรอบ ๆ (5) ตาพายุ — ลูกดูดคนเข้าต่อเนื่อง 2–3 วิ (6) ลมย้อนแทงหลัง — พุ่งไปโผล่หลังคนที่เพิ่งโดนลูกแล้วฟัน
