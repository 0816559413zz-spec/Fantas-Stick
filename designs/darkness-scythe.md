- ใบมีด: โค้งแบบ A (ความโค้งสะสมจากโคนแบบครึ่งวงกลม ขึ้นนิดเดียวแล้วลงนุ่ม) • ใบแคบลงนุ่ม ๆ แล้วปลายเรียวแหลมยาว • 2 ชั้น: **ชั้นบนดำสนิท 0% แสง** (วัสดุ `sc_void` = Background shader → glTF `KHR_materials_unlit`) • ชั้นล่างไล่ตามความยาว ต้นดำเข้ม → กลางเทาดำ → ปลายออกเทา (vertex color)
- ตัวเคียวดำสนิท (`sc_black` #070709) • ไม่มีน้ำเงิน • ลายบนใบเอาออกหมด (ให้ VFX ทำหน้าที่แทน)

## VFX (studio/darkness-scythe.js → FXCODE `studio_darkness_scythe`)
- เอฟเฟกต์: `assets/fx/darkness/scythe_idle.fx.json` (A), `scythe_idle_b` (B), `scythe_idle_c` (C — ล่าสุด) • arg `wrap` = A/B/C
- เคียวลอยหมุนควงข้าง **ขวา** ตัว (anchor ในสตูดิโอ: +z = หน้า, −x = ขวา) • scale 1.6 → สูง ~3.5 ม. (~1.8 เท่าตัวละคร — ผู้ใช้ขอ "ใหญ่กว่านี้อีก")
- อัปเดตทุกเฟรมด้วย `onBeforeRender` (ไม่แก้ studio.js) • เวลาใช้ `stVnow` ของสตูดิโอ
- ผู้ใช้ตัดสินแล้ว: **เอาเส้นฟุ้งเยอะ ๆ บนใบออก** (แบบ A/B มีเส้นฟุ้ง 96 เส้น = ไม่เอา) • พันด้ามแบบเกลียวแน่น (A) / เกลียวหลวม (B) = ยัง "ไม่ดีพอ"
- แบบ C (ล่าสุด, ยังไม่ได้ส่งให้ผู้ใช้ดู): ไม่มีเส้นบนใบ • 2 เส้นหมึกเรียบหนา-บาง ห่วงใหญ่ ก้นหอยบนสุด — ตาม `scythe_ink_ref.png`

## ทำต่อ
1. ส่ง GIF แบบ C (`shots/scythe_idle_c.gif` หรือ `designs/darkness_ref/scythe_idle_c.gif`) ให้ผู้ใช้ดู แล้วปรับเส้นหมึกให้เหมือน ref มากขึ้น: ห่วงลอยออกนอกด้ามชัดกว่านี้, ปลายสะบัดเป็นเปลว, เพิ่มเปลวดำเล็ก ๆ 2–3 อันบนสันใบช่วงโคน (ใน ref มี)
2. ผู้ใช้เคยบอกว่า "ค่อนข้างเยอะ อาจกลบทรงเคียว" + "ตอนฟันพุ่งเยอะกลายเป็นหาง (tail)" → ตอนทำท่าฟัน BA ให้หมึกพุ่งเป็นหางตามคม
3. เมื่อผ่าน: ผูกเคียวกับตัวละครในเกมตอนมีคลาส Darkness (ลอยข้างตัว, ท่าฟัน BA ตาม `designs/darkness.md` §BA เคียว)
4. ทำ GIF จากสตูดิโอ: `node tools/headless.js --url "studio.html?fx=darkness/scythe_idle_c&sheet=<0.1..2.8>&cam=front&dist=6&at=self&map=test&save=X" --wait-shot X` แล้วตัดช่อง 400×225 ทีละเฟรมเป็น GIF (ดูคำสั่งใน CHANGELOG วันนี้)

## สถานะล่าสุด (2026-11-19 — ผู้ใช้อนุมัติ)
- ใช้ `darkness/scythe_idle_c` (arg `wrap:"C"`) เป็นตัวจริง
- **เปลวบนใบ (อนุมัติ):** หมึกชุดเดิมของแบบ B (เส้น + หยดตามสัน) แต่ตัดช่วงที่ม้วนหลุดไกล (พลูมพุ่งขวาบน) ทิ้ง • เส้นเริ่มจากสันจริง (k 0–0.06) • มี "แผ่นเปลว" ต่อเนื่องงอกจากสัน ยอดเป็นลิ้นไฟหยักวิ่งตามใบ บางช่วงลิ้นหลุดลอยขึ้น โคนแหว่งแป๊บแล้วลุกใหม่ — ผู้ใช้ชอบเพราะ "ดูเป็นเปลวไฟจริง texture เดียวกันลุกไหม้"
- **ด้าม (อนุมัติ):** ดำสนิทไม่รับแสง ไม่มีหมึกพัน (โค้ดหมึกเส้นเดียวตาม ref ยังอยู่ เปิดด้วย `args.shaftInk`) • **เปลวดำที่ปลายล่าง** งอกจากการ์ดเพชร/หนาม เผาขึ้นเอียงไปทาง +x (ทางเดียวกับใบ)
- บทเรียน: ผู้ใช้หงุดหงิดเมื่อเดา — ถามด้วยรูปวงสี/ตัวเลือกก่อนทุกครั้งที่คำอธิบายกำกวม และอย่าสร้างของใหม่เมื่อผู้ใช้ขอ "เอาอันเดิมกลับมา" (โค้ดเก่าอยู่ในแบบ A/B)
- ทำต่อ: ท่าฟัน BA (หมึกพุ่งเป็นหางตามคม) • ผูกเข้าคลาส Darkness ในเกม

## ท่าฟัน BA (2026-11-19 — รอบ 4 ยังไม่ผ่าน)
- พรีวิว: `darkness/scythe_ba` (arg `mode:"ba"`, cycle 2.0 s) • โค้ด `baPose()` ใน `studio/darkness-scythe.js` (หางคำนวณจากท่าย้อนหลัง ไม่ใช้ history เฟรม)
- รอบ 4: ดึงเคียวเข้ามาหมุน 360° → พุ่งออกระยะ 220 ค้างสั่น → เหวี่ยงวงโค้งรัศมีคงที่ (ตามระยะ) • สลับซ้าย/ขวาทุกครั้ง • ปลายหางมีเปลว + ถ่านดำลอยขึ้น
- ผู้ใช้บอก "ยังต้องแก้" แต่ยังไม่ได้บอกจุด → ถามก่อน (ตัวเลือก: ท่าก่อนฟัน / วงฟัน-ระยะ / หาง-เปลว / จังหวะ) อย่าเดา
- GIF: render `sheet=2.0..5.95 step 0.05` ทั้ง `cam=game` และ `cam=top`
- **รอบ 5 (ผู้ใช้ 2026-11-19):** หางขึ้นเฉพาะตอนเหวี่ยงฟัน (ไม่ตามตลอด) • ด้ามมีหางเป็นชั้นจางกว่า ต่อติดกับหางใบตามทางฟันจริง • ปลายใบหางยื่นเลยปลายไปอีกนิดและชัดกว่า • เปลวไฟแบบปลายล่างเคียวไปอยู่ที่ปลายหางด้วย • ท่าเหวี่ยง (วง ~270°, เคียวไปไกล) ยังไม่ได้แก้
- **รอบ 6 (ผู้ใช้ 2026-11-19):** ทั้งเคียวมีหาง ใบดำเข้มสุด ด้ามเป็นเทาเข้ม→เทาอ่อน • วงฟันโค้งกลม ครึ่งวงแต่ไม่ถึง 180° อยู่ด้านหน้า (`A` 1.8 → 1.05) • หางละเอียดขึ้น
- **รอบ 7–8 (ผู้ใช้ 2026-11-19):** หางด้ามยาวเท่าหางใบ • เคียวหันไปข้างหน้าตลอด ด้ามชี้ออกจากตัว (เดิมด้ามนอนตามทางกวาด หางด้ามเลยเป็นเส้นบาง) → ผืนเทากว้าง ใบดำขอบนอก
- **รอบ 10 (ผู้ใช้ 2026-11-19) ลำดับท่า:** ว่าง = แนวตั้ง ลอยวนรอบตัวช้า ๆ (แบบ B) • ฟันแรกเริ่มจากฝั่งที่เคียวอยู่ อยู่ข้างหลังให้ไปข้างใดข้างหนึ่งก่อน • หลังฟันค้าง 0.3 วิ แล้วควง 0.3 วิ แบบท่าควงโล่ แต่มีละอองหมึกสาดออกมามากกว่า ระหว่างควงเลื่อนไปจุดเตรียมฟันต่อ • ฟันต่อจากฝั่งที่จบ (สลับซ้าย-ขวา) • ไม่ได้ฟันเกิน 2 วิ เคียวกลับแนวตั้ง • ตอนฟันและเตรียมอยู่แนวนอนตลอด • โค้ด `baState()`
- **รอบ 11 (ผู้ใช้ 2026-11-19):** ควงหลังฟัน = VFX ควงแบบโล่ (`stDarkShieldInk` + `stDarkShieldFlames`) + เส้นเปลวดำ 3 เส้นคนละทิศ ควงตามเคียวแล้วหาย • ละอองหมึกใหญ่ขึ้นให้เห็น
- **รอบ 12 (ผู้ใช้ 2026-11-19):** หลังควงต้องไม่ตัด/วาร์ปไปทิศใหม่ ให้ค่อย ๆ ช้าลงจนหยุด • ควงไปจุดเตรียมฟันต่อโดยตรง ไม่ควงเข้าหาตัวก่อน • ฟันต่อเร็วขึ้นเพราะอยู่ที่จุดพร้อม • ตอนควงเร็วจนแทบไม่เห็นเคียวในจาน
- **รอบ 13 (ผู้ใช้ 2026-11-19):** ควงไปจุดเตรียมให้เลยไปทางหลังของฝั่งนั้นอีกนิด (ไม่มาก) = วงฟันต่อกว้างขึ้นและลื่น • เส้นเปลวลดลง ยอดแหลมไม่โค้ง

## BA โดนเป้า (ผู้ใช้อนุมัติ 2026-11-19)

- ทุก BA ที่โดน: รอยฟันดำ + เส้นขาวบางตามคม ลอยออกมาหน้าตัวเป้า (ไม่จมเข้าตัว) 0.3 วิ • เป้าสะดุ้ง
- โดนเป้ามีตรา: เคียวเงาขนาดเท่าเคียวจริง ดำโปร่ง 70% มีเปลว/หมึกเหมือนเคียวจริง โผล่ 0.3 วิหลังโดน ลอยสูงหลังเป้า (สุ่มหลัง / หลังซ้าย / หลังขวา เอียงเฉียงบ้าง)
