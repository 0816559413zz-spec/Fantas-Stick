1หน้าจอหลัก (แท็บ ✨ เอฟเฟกต์)

เอฟเฟกต์ 1 ไฟล์ประกอบจากหลายชั้น (เช่น แสงวาบ + หนามน้ำแข็ง + ประกาย + เสียง) แต่ละชั้นเล่นตามเวลาบนไทม์ไลน์ ภาพในจอตรงกลางคือของจริงในเกม ไม่ใช่ภาพจำลอง

  1. 4 แท็บ: ✨ เอฟเฟกต์ (ประกอบเอฟเฟกต์) · 🧊 โมเดล (ปั้นรูปทรง 3D) · 🎞 ภาพ (วาดภาพเคลื่อนไหว) · 🔥 ไฟ 3D (จำลองไฟจริง)
  2. ไฟล์: ชื่อไฟล์ที่เปิดอยู่ (มี ● สีส้ม = ยังไม่บันทึก) · ＋ ใหม่ · 💾 บันทึก Ctrl+S · เป็น… (บันทึกชื่อใหม่) · ↶ ย้อน Ctrl+Z · ↷ ทำซ้ำ Ctrl+Y
  3. ธาตุ (เปลี่ยนชุดสีทั้งเอฟเฟกต์ในคลิกเดียว) · ความแรง (ขยาย/ลดทั้งเอฟเฟกต์)
  4. ตั้งค่าฉาก: 🗺 แผนที่ (ลองทั้งฉากสว่างและฉากมืด) · 📍 จุดเล่น (หน้าเรา / ที่ตัวเรา / ไกล) · ⚙ ระดับกราฟิก
  5. ตรวจงาน: 🖼 แผ่นภาพ (ถ่ายหลายจังหวะไว้ในรูปเดียว) · 📷 ถ่ายรูป · 🎮 ลองในเกม · ❔ วิธีใช้ + ปุ่มลัด
  6. คลังเอฟเฟกต์: ช่อง 🔍 ค้นหา · คลิกชื่อเพื่อเปิด · คลิกหัวกลุ่มเพื่อพับเก็บ · กลุ่ม แม่แบบเริ่มต้น ใช้เริ่มงาน
  7. จอดูผล: ลากเมาส์ = หมุนกล้อง · ล้อเมาส์ = ซูม
  8. มุมกล้อง: กล้องเกม · ข้าง · หน้า · บน · หมุนเอง (กด 1–5 ก็ได้)
  9. ตัวเลขสุขภาพ: อนุภาค · ขาวจ้า % (จอสว่างจนขาวไหม) · บังตัว % (บังตัวละครไหม) · draw · ms จุดเขียว = ดี สีส้ม = เกิน
  10. ปุ่มเล่น: เล่น/หยุด ความเร็ว และ ＋ เพิ่มชั้น (ดูข้อ 2)
  11. ไทม์ไลน์: 1 แถว = 1 ชั้น แถบสียาวแค่ไหน = ชั้นนั้นเล่นนานแค่นั้น
  12. ช่องปรับค่า: ค่าของชั้นที่เลือกอยู่ ถ้ากด “⚙ ตั้งค่าไฟล์ / ผูกกับท่า” จะเป็นค่าของทั้งไฟล์
  13. แถบล่างสุด: ชี้เมาส์ที่ปุ่มไหนก็ได้ ตรงนี้จะบอกว่าปุ่มนั้นทำอะไร · ด้านขวาบอก ✓ ตรวจผ่าน · ✓ บันทึกแล้ว · 🔌 บันทึกลงโปรเจกต์ได้ · ⌨ ปุ่มลัด

แผงซ้าย ขวา และล่าง ลากที่เส้นขอบเพื่อขยายหรือย่อได้ · ดับเบิลคลิกที่เส้นขอบ = พับแผงเก็บ (ดับเบิลคลิกอีกครั้งเพื่อกางคืน) โปรแกรมจำขนาดไว้ให้ครั้งหน้า

2เล่นดู + ไทม์ไลน์

  1. ปุ่มเล่น: ⏮ กลับจุดเริ่ม Home · ▶/⏸ เล่นหรือหยุด Space · ⟲ เล่นใหม่ตั้งแต่ต้น R · 🔁 วนซ้ำ L
  2. เวลา: ตอนนี้อยู่วินาทีที่เท่าไร / ยาวทั้งหมดกี่วินาที กด ← → เพื่อเลื่อนทีละนิด
  3. ความเร็ว: 0.1× = ช้ามาก (ใช้ดูรายละเอียด) … 1× = ปกติ
  4. ＋ เพิ่มชั้น Shift+A: เพิ่มชิ้นส่วนเอฟเฟกต์ (ดูข้อ 4)
  5. ⚙ ตั้งค่าไฟล์ / ผูกกับท่า: ค่าของทั้งไฟล์ ผลตรวจ และการผูกกับท่าในเกม (ข้อ 6)
  6. ไม้บรรทัดเวลา: คลิกหรือลาก = กระโดดไปเวลานั้น เส้นทองคือเวลาปัจจุบัน (คลิกที่แถวว่างก็กระโดดได้เหมือนกัน)
  7. ⋮⋮ จับลาก ขึ้น/ลง = เรียงลำดับชั้น
  8. 👁 ซ่อนชั้นชั่วคราว H · S ดูชั้นนี้ชั้นเดียว · ⋯ เมนูของชั้น (ปุ่มพวกนี้โผล่เมื่อชี้เมาส์ที่แถว)
  9. แถบสี: คลิกเพื่อเลือกชั้น · ลากทั้งแถบ = เลื่อนให้เริ่มเร็วหรือช้าลง · ลากขอบขวา = ยืดหรือหดเวลา

คลิกขวาที่ชั้น = เมนูลัด

คลิกขวาที่ชื่อชั้นหรือแถบสี (หรือกด ⋯) จะได้เมนูนี้: เปลี่ยนชื่อ F2 · ทำซ้ำ Ctrl+D · ซ่อนชั่วคราว H · เล่นชั้นนี้ชั้นเดียว · ย้ายขึ้น/ลง · ให้เริ่มที่หัวเล่น (ย้ายแถบมาเริ่มตรงเส้นทองพอดี) · ลบชั้น Delete

ดับเบิลคลิกที่ชื่อชั้นก็เปลี่ยนชื่อได้ · ปุ่ม ↑ ↓ เลือกชั้นบน/ล่าง · Esc เลิกเลือก

3ปรับค่าของชั้น (สี ขนาด รูปทรง)

คลิกชั้นในไทม์ไลน์ ช่องขวามือจะแสดงค่าของชั้นนั้น เปลี่ยนแล้วจอจะเปลี่ยนตามทันที ปุ่ม ↺ ข้าง ๆ แต่ละช่องใช้คืนค่าเดิม จุดสีส้มหน้าชื่อ = ช่องที่แก้ไปแล้ว คลิกหัวข้อ (เช่น “ค่าของรูปทรง 3D”) เพื่อพับ/กางกลุ่มได้

  1. หัวการ์ด: ชื่อชั้น ชนิด เวลาเริ่ม และอายุ
  2. 🔍 หาค่า: พิมพ์ เช่น “สี” “ขนาด” หรือ size จะเหลือเฉพาะช่องนั้น (กด Esc ล้าง)
  3. รูปทรง: กดเลือกรูปได้เลย เช่น ลูกกลม โดม วงแหวน กรวย หนาม ลำแสง ส่วน model = โมเดลที่ปั้นเองในแท็บ 🧊
  4. ชื่อโมเดล (เมื่อเลือก model) พิมพ์ชื่อหรือเลือกจากรายการ
  5. วัสดุ = เนื้อของสิ่งนั้น: ice (น้ำแข็ง) · fire (ไฟ) · energy (พลังงาน) · tex (ใช้ภาพจากแท็บ 🎞) ฯลฯ
  6. สี: กดจุดสีสำเร็จรูป (ตามธาตุ) หรือกดช่องสียาวเพื่อเลือกสีเอง
  7. ขนาด: ใส่ตัวเลข (หน่วยเมตร) หรือใช้ เส้นโค้ง เพื่อให้ขนาดเปลี่ยนไปตามเวลา
  1. เส้นโค้ง: แกนซ้าย→ขวา = เวลา แกนล่าง→บน = ค่า · ลากจุด ได้ · ดับเบิลคลิก = เพิ่มจุด · คลิกขวา = ลบจุด
  2. ความนุ่มของเส้น: linear (ตรง) · in (เริ่มช้า) · out (จบช้า) · inout · step (กระโดด)

ตัวเลื่อนทุกอันลากได้ หรือจะพิมพ์ตัวเลขลงในช่องข้าง ๆ ก็ได้ ชื่อภาษาอังกฤษตัวเล็กมุมขวา (เช่น scale) คือชื่อจริงในไฟล์ ใช้ตอนบอก Claude ว่าจะให้แก้ช่องไหน

4เพิ่มชั้นใหม่ (＋ เพิ่มชั้น)

กด ＋ เพิ่มชั้น ที่แถบไทม์ไลน์ หรือกด Shift+A ชั้นใหม่จะเริ่มตรงเส้นทอง (เวลาปัจจุบัน)

  1. ช่องค้นหา: พิมพ์ เช่น “ไฟ” “อนุภาค” “ring” แล้วกด Enter = เพิ่มอันแรกทันที
  2. หมวด: แสงและแฟลช · รูปทรง 3D และไฟ · อนุภาคและเศษ · ธาตุพิเศษ · ทั้งจอและเสียง · ขั้นสูง
  3. ชนิดชั้น: คลิกเพื่อเพิ่ม (ใต้ชื่อมีคำอธิบายสั้น ๆ)

5ทำเอฟเฟกต์ใหม่ (＋ ใหม่)

  1. ชื่อไฟล์: ใส่เป็น ธาตุ/ชื่อท่า เช่น ice/frost_nova (ใช้ตัวอังกฤษเล็ก ตัวเลข และ _ เท่านั้น)
  2. ธาตุ: เลือกชุดสี เช่น fire ice storm
  3. กดแม่แบบที่ใกล้ที่สุด เช่น explosion (ระเบิด) · beam (ลำแสง) · slash (ฟัน) · shield (โล่) · ice_spikes (หนามน้ำแข็ง) · projectile (ลูกยิง)
  4. ปรับต่อตามข้อ 3–4 แล้วกด 💾 บันทึก

6บันทึก ตรวจ และใส่ในเกม

  1. ตรวจไฟล์: ถ้าขึ้น ✓ ผ่าน แปลว่าใช้ได้ ถ้าขึ้น ✗ สีแดง แปลว่ามีจุดต้องแก้ ข้อความจะบอกว่าผิดตรงไหน (ดูผลย่อได้ที่แถบล่างสุดของจอ คลิกที่นั่นเพื่อเปิดช่องนี้)
  2. ผูกกับท่าในเกม: พิมพ์หรือเลือกชื่อท่า → เลือก เพิ่มทับ (เล่นซ้อนกับภาพเดิม) หรือ แทนที่ (ใช้ภาพใหม่แทนทั้งหมด) → กด ผูก
  3. ผูกไว้แล้วกับท่าไหน: รายการท่าที่ใช้เอฟเฟกต์นี้อยู่ (กด ลบ เพื่อเลิกผูก)
  1. กด 💾 บันทึก (Ctrl+S) แล้วจะมีกล่องแจ้งที่ด้านล่างจอ
  2. กด 🎮 ลองในเกม เพื่อเปิดเกมจริงแล้วกดท่าดูว่าสวยไหม
  3. ถ้าพอใจ ให้บอก Claude ว่า “push” งานจะขึ้น GitHub แล้วเพื่อนก็จะได้ด้วย

ชื่อท่าในเกมดูยาก ถ้าไม่แน่ใจ บอก Claude ได้เลยว่า “ผูกเอฟเฟกต์นี้กับท่า … ให้หน่อย”

7🧊 ปั้นโมเดล (หนาม ผลึก ปีก ใบมีด โดม…)

ปั้นรูปทรงจากชิ้นสำเร็จรูป ไม่ต้องใช้ Blender โมเดล 1 ตัวประกอบจากหลายชิ้นส่วน แต่ละชิ้นปรับจำนวน ขนาด เอียง บิด งอ และทำซ้ำเป็นวงได้

  1. คลังโมเดล: คลิกเพื่อเปิด มีตัวอย่างให้ 16 แบบ (poly_horn = ตัวอย่างปั้นเอง)
  2. ＋ ใหม่: เริ่มจากว่างเปล่าหรือก๊อปจากตัวอย่าง
  3. จอ: คลิกที่ชิ้น = เลือก · ลากลูกศรสี = ขยับ (แดง = ซ้ายขวา · เขียว = ขึ้นลง · น้ำเงิน = หน้าหลัง)
  4. ＋ ชิ้นส่วน: เพิ่มชิ้นใหม่ (ดูรูปถัดไป)
  5. ย้าย G · หมุน R · ขนาด S ใช้เปลี่ยนโหมดของลูกศรบนจอ (เหมือน Blender)
  6. มุมมอง: โครงลวด W · ดู: ดินปั้น (สีเรียบ ดูทรงง่าย) / วัสดุจริง · เลือกวัสดุ · เลือกธาตุ
  7. ➕ ใส่ในเอฟเฟกต์: ส่งโมเดลนี้ไปเป็นชั้นใหม่ในแท็บ ✨ ทันที
  8. ⬇ .glb: ส่งออกไฟล์ไปเปิดใน Blender
  9. รายการชิ้นส่วน: 👁 ซ่อน H · ↑↓ ลำดับ · ⧉ ก๊อป Ctrl+D · ✕ ลบ Delete
  10. ค่าของชิ้นที่เลือก: แบบชิ้นส่วน · จำนวนหนาม · รัศมี · สูง · กว้าง · เอียง · บิด · งอ · ทำซ้ำเป็นวง · กระจก ซ้าย/ขวา
  11. 💾 บันทึก Ctrl+S

เมนู ＋ ชิ้นส่วน

✎ ปั้นเอง (ด้านบนของเมนู): ลูกบาศก์ · แผ่น · ทรงกระบอก · ทรงกลม · กรวย — เริ่มจากรูปง่าย ๆ แล้วดึง/ขยับจุดเองได้แบบ Blender (ดูหัวข้อถัดไป)

ชิ้นสำเร็จรูป 16 แบบ: ปรับด้วยแถบเลื่อนทางขวาอย่างเดียว ไม่ต้องจับจุด

💎 แท่งผลึก♛ มงกุฎหนาม⚠ กลุ่มผลึก✹ หนามรอบทิศ☾ ใบฟัน / เคียว🪶 พัด / ปีก🌀 เกลียว / พายุ〰 ท่อ (เขา หนวด)🎀 ริบบิ้น🏺 หมุนเส้น (โดม แจกัน)● ทรงกลม▮ กระบอก◎ โดนัท○ แผ่นวง★ ดาว■ กล่อง

ชี้เมาส์ค้างไว้บนปุ่มเพื่อดูคำอธิบาย ถ้าเป็นเอฟเฟกต์โผล่จากพื้น ให้ใช้ช่อง grow ในแท็บ ✨ จะทำให้หนามแต่ละอันงอกขึ้นทีละอัน

✎ ปั้นเองแบบ Blender (แบบง่าย)

ใช้เมื่อชิ้นสำเร็จรูปไม่ได้รูปที่ต้องการ: เริ่มจากลูกบาศก์/ทรงกระบอก ฯลฯ แล้วเลือกจุด ขอบ หรือหน้ามาดึง ย้าย หมุน ย่อขยาย เหมือน Blender แต่มีเครื่องมือแค่ที่จำเป็น ในคลังมีตัวอย่าง poly_horn (เขาโค้ง ทำจากลูกบาศก์ดึงขึ้น 3 ครั้ง + ทำให้เนียน)

  1. ✎ แก้จุด Tab: เข้า/ออกโหมดแก้จุด (ใช้ได้กับชิ้นแบบ ✎ ปั้นเอง)
  2. เลือกทีละ: ● จุด 1 · ╱ ขอบ 2 · ■ หน้า 3 — คลิกบนจอ = เลือก · Shift+คลิก = เลือกเพิ่ม/เอาออก · A = ทั้งหมด/ไม่เลือก
  3. เลือกเยอะ ๆ / ตัดวง: ▭ กรอบ B แล้วลากบนจอ (Shift = เพิ่ม · Ctrl = เอาออก) · ◎ เลือกวง L หรือ Alt+คลิกขอบ = เลือกทั้งวง (โหมดหน้า = แถบหน้ารอบชิ้น) · ✂ ตัดวง Ctrl+R = เพิ่มเส้นวงใหม่ตัดขวาง (เลือกขอบก่อน หรือกดแล้วคลิกขอบ)
  4. เครื่องมือ: ⇑ ดึงออก E · ▣ หดหน้าเข้า I · ◆ เติมหน้า F (จาก 3–4 จุด) · ⊕ รวมจุด M · ÷ แบ่งหน้าทั้งชิ้น · ⇅ กลับด้านหน้า · ✕ ลบ X
  5. นับ: จำนวนจุด · หน้า · และสิ่งที่เลือกอยู่
  6. จอ: จุด/ขอบ/หน้าที่เลือกเป็นสีส้ม · ลากลูกศรสีเพื่อขยับของที่เลือก
  7. ย้าย G · หมุน R · ขนาด S: เปลี่ยนแบบของลูกศรสี (ใช้กับจุดที่เลือก)
  8. รูปทรงที่ปั้นเอง: จำนวนจุด/หน้า และปุ่มเข้าโหมดแก้จุด
  9. ทำให้เนียน 0–3: แบ่งหน้าให้โค้งมน (เลข 1–2 พอ) ใช้คู่กับปิด “ผิวเหลี่ยม”
  10. ผิวเหลี่ยม: เปิด = เห็นเป็นเหลี่ยม (หิน ผลึก) · ปิด = ผิวเรียบ
  1. ＋ ชิ้นส่วน → ■ ลูกบาศก์ (จะเข้าโหมดแก้จุดให้เอง)
  2. กด 3 แล้วคลิกหน้าบน → กด E ดึงออก → ลากลูกศรเขียวขึ้น
  3. กด S แล้วลากลูกศรเพื่อย่อหน้าบน (ได้ทรงเรียว) ทำซ้ำ E หลายครั้งได้
  4. อยากได้รอยหยัก/ข้อปล้อง: กด 2 คลิกขอบแนวตั้ง แล้ว Ctrl+R ตัดวง → S ย่อ/ขยายวงใหม่
  5. กด Tab ออก → ตั้ง “ทำให้เนียน” = 2 และปิด “ผิวเหลี่ยม” → 💾 บันทึก

อยากได้ซ้ายขวาเท่ากัน (เช่น ปีก เขาคู่): เปิด กระจก ในกลุ่ม “ทำซ้ำ / กระจก” แล้วปั้นแค่ข้างเดียว · ผิดพลาดกด Ctrl+Z ย้อนได้เสมอ

8🎞 ทำภาพ / ภาพเคลื่อนไหว (ไฟ ควัน ระเบิด วงเวท…)

วาดภาพสำหรับเม็ดอนุภาคหรือการ์ดภาพ เลือกชนิด ปรับตัวเลื่อน และเลือกสี โปรแกรมจะวาดเป็นหลายเฟรมต่อกันเพื่อให้ขยับได้ หรือจะนำเข้ารูปของตัวเองก็ได้

  1. คลังภาพ: มีรูปตัวอย่างเล็กให้ คลิกเพื่อเปิด
  2. ดูภาพขยับ: เล่นวนให้ดู
  3. แผ่นเฟรมทั้งหมด: นี่คือไฟล์ภาพที่เกมใช้จริง
  4. ชนิดภาพ: เปลวไฟ · ควัน · ระเบิด · สายฟ้า · วังวน · คลื่นกระแทก · ประกายแตก · รอยฟัน · ดาว · แสงนุ่ม · วงแหวน · วงเวท · ลายนอยส์ · ภาพที่นำเข้าเอง · จำลองของไหลจริง
  5. ชุดสี: กดเลือกได้เลย (fire ice storm nature hex arcane gold blood smoke white) หรือกด “กำหนดสีเอง”
  6. 📥 นำเข้าภาพ: เลือกไฟล์ PNG/JPG หรือลากไฟล์มาวางบนภาพก็ได้ ถ้าเลือกหลายไฟล์จะเรียงเป็นเฟรมตามชื่อไฟล์
  7. ➕ เป็นเม็ดในเอฟเฟกต์ (อนุภาคหลายเม็ด) · ➕ เป็นการ์ดภาพ (ภาพแผ่นเดียวหันหาจอ)
  8. 🧪 ลองใน 3D: ดูภาพบนฉากจริง 1 = ภาพ · 2 = 3D
  9. 💾 บันทึก: วาดไฟล์ภาพ .png ให้เอง
  10. ตัวเลื่อน: ปรับขนาด ความเร็ว ความปั่นป่วน ฯลฯ ภาพจะวาดใหม่ทันที

9🔥 ไฟ 3D (จำลองไฟจริง)

คอมพิวเตอร์จะจำลองไฟเป็นก้อน 3 มิติจริง ๆ แบบเดียวกับ Blender แต่ใช้เวลาแค่ 1–3 วินาที ใช้ทำเสาไฟ กำแพงไฟ วงไฟ กองไฟ หรือระเบิด

  1. แบบสำเร็จรูป: column (เสาไฟ) · wall (กำแพงไฟ) · ring (วงไฟ) · bonfire (กองไฟ) · burst (ระเบิดครั้งเดียว)
  2. ▶ จำลอง Enter: กดทุกครั้งหลังเปลี่ยนค่า แล้วรอสักครู่
  3. ข้อมูล: ความละเอียด · จำนวนเฟรม · ขนาดไฟล์ (ควรไม่เกินประมาณ 1–2 MB)
  4. ไฟในฉากจริง หมุนกล้องดูได้
  5. ปรับไฟ: ขนาดต้นไฟ · ลอยขึ้น · ม้วนตัว · ปั่นป่วน · ดับเร็ว (เปลวสั้น) · ลมข้าง · รายละเอียดลิ้นเปลว · สั่นไหว
  6. ➕ ใส่ในเอฟเฟกต์: ส่งไฟนี้ไปเป็นชั้นในแท็บ ✨
  7. 💾 บันทึก
  8. คลังไฟ 3D ที่ทำไว้

ไฟ 3D ใช้ได้เฉพาะสีไฟ (ส้ม แดง เหลือง) ถ้าอยากได้ไฟสีอื่น ให้ใช้แท็บ 🎞 ภาพ → “จำลองของไหลจริง” แล้วเลือกชุดสีแทน

  3. 💾 บันทึก

  4. 💾 → 🎮 ลองในเกม

  1. แท็บ 🧊 → ＋ ใหม่ → ใส่ชิ้น ♛ มงกุฎหนาม
  2. ปรับจำนวน/สูง → 💾
  3. ➕ ใส่ในเอฟเฟกต์
  4. ในแท็บ ✨ ตั้งวัสดุ ice และเปิดช่อง grow

✎ปั้นรูปทรงเอง (เขา ฟัน ใบดาบ)

  1. แท็บ 🧊 → ＋ ชิ้นส่วน → ■ ลูกบาศก์
  2. 3 คลิกหน้า → E ดึงออก → ลากลูกศร (ทำซ้ำได้)
  3. Tab ออก → ทำให้เนียน 2 → 💾

🖼ใช้รูปที่วาดเอง

  1. แท็บ 🎞 → 📥 นำเข้าภาพ (หรือลากไฟล์มาวาง)
  2. ถ้าเป็นภาพหลายช่อง ให้ใส่จำนวน คอลัมน์ × แถว
  3. 💾 → ➕ เป็นเม็ด หรือ ➕ เป็นการ์ดภาพ

🔥เสาไฟหรือระเบิดไฟสมจริง

  1. แท็บ 🔥 → ＋ ใหม่ → column หรือ burst
  2. ปรับค่า → ▶ จำลอง (ทำซ้ำจนชอบ)
  3. 💾 → ➕ ใส่ในเอฟเฟกต์

💬ให้ Claude ทำให้

พิมพ์บอกเป็นภาษาไทยได้เลย เช่น “ทำเอฟเฟกต์ระเบิดน้ำแข็งให้ท่า … ให้สีฟ้าเข้มขึ้น แล้วมีหนามงอกจากพื้น” Claude ก็ใช้โปรแกรมเดียวกันนี้ทำ แล้วเปิดดูผลได้ในสตูดิโอ
